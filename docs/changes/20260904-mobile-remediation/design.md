## 背景与目标

当前实现把原型、页面和接口之间的决策混在单体 `App.vue` 中，导致视觉和交互偏差。本变更先建立一个能截图、能操作、能定位的黄金页面，作为后续实现的硬性基线。

## 非目标

- 不复制外部项目业务页面、文案或资源。
- 不修改后端数据库或新增接口。
- 不在本阶段重做批次、成员、操作记录和我的页面。

## 方案与影响范围

- 设计阶段：新增本目录文档和原生 HTML 原型。
- 实现阶段：原型确认后拆分 `layouts`、`pages`、`components`、`stores`、`api` 和 `composables`。
- 参考项目：必须在实现前补充 commit、具体文件和移植说明；当前环境无法读取 GitHub 远端 SHA，故暂不放行实现阶段。

## 验收标准

- 原型可直接打开并完成工作区切换、新建批次、导航和批次入口演示。
- 390×844、430×932 截图无溢出和遮挡。
- 页面/API/权限契约和 ID 注册表覆盖所有关键节点。
- 用户确认原型后，才创建 Vue 技术实现任务。
