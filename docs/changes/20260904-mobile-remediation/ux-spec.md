# UX/UI 规格：工作区概览黄金页面

## 结论

页面采用真正的移动端工作台结构：顶部固定工作区上下文，中部按任务分组的单列内容，底部固定主导航。视觉使用白色表面、深靛蓝主色和浅灰画布，不使用 PC 表格、宽容器、渐变或装饰性卡片；原型位于 `prototype/index.html`。

## 页面地图

```text
工作区概览
  ├─ 顶部工作区切换
  ├─ 概览统计
  ├─ 最近批次
  ├─ 快捷操作
  └─ 底部导航
```

## 页面规格

### 页面：工作区概览

- 核心任务：理解当前工作区并进入批次、成员和操作记录任务。
- 进入条件：已登录且已选择工作区。
- 离开/下一步：打开工作区切换、批次详情、批次列表、成员或操作记录。
- 信息层级：工作区上下文 → 页面标题/主操作 → 统计 → 最近批次 → 快捷操作 → 底部导航。
- 主操作：新建批次。
- 次要操作：查看全部批次、管理成员、查看操作记录、切换工作区。
- 危险操作与确认：概览不直接放置删除和移除操作。

#### 字段与控件

| 区域 | 字段/控件 | 控件类型 | 必填/可选 | 校验或说明 |
|---|---|---|---|---|
| 顶部 | 当前工作区 | Button + Popup | 必填 | 名称超长省略，选项包含角色 |
| 标题 | 工作区名称、当前角色 | 文本 | 必填 | 不展示无业务价值的空间说明 |
| 标题 | 新建批次 | Primary Button | 按权限 | owner/admin 可用 |
| 统计 | 成员、批次、操作记录 | Metric Strip | 必填 | 只读当前工作区事实 |
| 最近批次 | 名称、创建时间、角色、状态 | List Item | 可选 | 空数据显示下一步 |
| 快捷操作 | 成员、批次、操作记录 | Command List | 可选 | 是操作入口，不做成宣传卡片 |
| 底部 | 工作区、批次、操作记录、我的 | TabBar | 必填 | 当前页高亮 |

#### 交互与反馈

- 成功：创建批次后关闭弹窗、刷新数据并进入批次列表。
- 失败：保留输入，显示页面或操作级错误。
- 加载：保留页面骨架，禁用提交和切换。
- 空数据：最近批次显示“暂无批次”和“新建批次”入口。
- 弹窗：工作区切换使用底部 Popup，新建批次使用 Dialog；批次详情后续独立实现。

## 状态覆盖

- Loading：统计和列表位置保留，显示加载指示。
- Empty：空批次提供创建入口，空工作区提供切换入口。
- Error：页面级错误可重试，输入值不丢失。
- 无权限：保留只读数据，隐藏或禁用创建操作并说明原因。
- Disabled：提交中、无工作区或权限不足时禁用对应控件。
- 成功反馈：使用具体动作 Toast。
- 危险操作确认：本页不承载危险操作，后续批次/成员页面单独确认。

## 响应式与视觉边界

- 桌面端：内容保持移动端最大宽度 480px，居中显示，不扩展为 PC 后台布局。
- 移动端：390×844 和 430×932 无横向溢出；触控目标最小 44px；列表项垂直间距 12px 以上。
- 标签和值：后续详情表单采用同一行布局，标签右对齐，说明文字小于标签。
- 颜色：主色使用深靛蓝 `#3657c8`，危险色 `#b42318`，中性背景 `#f5f7fb`。
- 禁止模式：不使用橘色主色、渐变、宽表格外框、嵌套卡片和无业务说明文案。
- 原型：`prototype/index.html`
