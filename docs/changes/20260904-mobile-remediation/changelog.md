# 变更记录：移动端黄金页面整改

## 2026-09-04

- 记录移动端实现偏离原型的原因和流程缺口。
- 新增工作区概览产品定义、UX 规格、页面/API/权限契约和 `data-ai-id` 注册表。
- 新增可运行的移动端黄金页面 HTML 原型。
- 明确原型确认、接口契约和视觉/交互/ID 三项验收门禁。
- 暂不修改 `apps/web`，等待原型确认后进入 Vue 重构。
- 阶段一：抽取 `WorkspaceOverview` 概览组件，按黄金页面原型补齐工作区上下文、统计、最近批次、快捷操作和稳定 `data-ai-id`；其他页面暂不改动。
- 阶段一 Web typecheck/build 通过，等待工作区概览页面人工和移动视口验收后再进入下一阶段。
- 阶段一修正：应用外壳限制为 480px 移动端容器，统一黄金页面深靛蓝主题，移除不存在路由的 TabBar route 模式，确保概览列表和底部导航按原型显示。
- 阶段一重构：新增 `layouts/MobileShell.vue`，使用 Vant NavBar/TabBar 统一移动端壳层，App 不再直接承载旧顶部栏和底部导航。
## 2026-09-04 入口重建（阶段一）

- `App.vue` 收敛为唯一的 `router-view` 挂载入口，不再承载认证、页面状态、业务弹窗和页面模板。
- 新增独立 `LoginPage.vue`、`WorkspacePage.vue` 和 `PlaceholderPage.vue`。
- 新增 `auth` Pinia store，集中管理登录、验证码、会话恢复和退出登录。
- 路由拆分为登录、工作区、批次、成员、操作记录和我的；批次等页面暂以占位页承接，待工作区概览验收后分阶段实现。
- 工作区首页继续复用已确认的 `WorkspaceOverview`、`MobileShell`、页面契约和 `data-ai-id`。

## 2026-09-04 批次列表（阶段二）

- 新增独立 `BatchesPage.vue`，从路由进入批次列表，不再使用占位页。
- 列表支持当前工作区范围、名称搜索、状态筛选、创建时间、我的角色和状态标签。
- 新建批次使用独立 Dialog；删除仅在列表项发起，并使用红色按钮和二次确认。
- 批次详情仍保留为下一阶段，当前点击列表项进入详情占位页。

## 2026-09-04 移动端比例调整

- 修正触摸设备上的响应式判断，避免 iPhone 被误判为桌面端 480px 预览。
- 缩小顶部品牌、工作区入口、页面主按钮和底部导航的视觉尺寸，同时保留触控区域。
- 批次筛选比例调整为搜索框优先、筛选框紧凑布局。
- 批次列表改为标题/元信息两行结构，删除移入更多菜单并保留二次确认。

## 2026-09-04 交互控件视觉修正

- 快捷操作改为无边框、圆角、整行可点击的 Vant Button，避免继续呈现为表格/Cell 列表。
- “查看全部”改为轻量文本按钮，去除突兀边框。
- 批次筛选下拉统一为紧凑 40px 控件，降低默认 Vant 菜单的视觉重量。
- 批次状态标签固定在列表项右上区域，元信息保持独立第二行。

## 2026-09-04 批次详情（阶段三）

- 新增独立 `BatchDetailPage.vue`，替换 `/batches/:id` 占位页。
- 展示批次基本信息、状态、角色、创建时间和参与人列表。
- 添加参与人使用独立 Dialog，并通过工作区成员 Picker 选择可添加成员。
- 成员角色使用 Tag；角色调整、移除参与人均保留权限判断和危险操作确认。

## 2026-09-04 批次详情移动端布局修正

- 批次名称编辑框增加明确的输入边界，避免被误认为纯展示。
- 创建时间从三列摘要卡调整为两列摘要布局，避免窄屏截断。
- 批次列表改为自定义移动端列表项，状态标签固定在右上角，箭头和更多操作独立定位。
- 搜索框和状态筛选统一可见边界及 40px 控件高度。

## 2026-09-04 首页与详情契约对齐

- 首页最近批次与批次列表统一使用同一套移动端两行列表项结构。
- 批次详情摘要改为单列字段行，创建时间完整展示，不再使用窄屏三列/两列卡片。
- 批次名称编辑字段明确使用带边界输入框，并统一 label/value 对齐方式。

## 2026-09-04 工作区成员页（阶段四）

- 新增独立 `MembersPage.vue`，替换 `/members` 占位页。
- 展示成员角色标签和邀请时间，owner 行不可移除或降级。
- 邀请成员使用独立 Dialog，角色使用 Picker；成功后展示一次性 token 并刷新成员事实列表。
- 成员角色调整使用 Picker，移除成员使用红色操作和二次确认。

## 2026-09-04 操作记录页（阶段五）

- 新增独立 `OperationRecordsPage.vue`，替换 `/audit` 占位页。
- 仅展示当前工作区的操作记录，按时间、操作者、对象和动作呈现。
- owner/admin 可刷新记录；其他角色显示明确的无权限状态。
- 覆盖空数据、当前工作区上下文和操作记录定位 ID。

## 2026-09-04 移动端横向溢出修复

- 应用壳层、主内容和页面根节点统一限制为视口宽度并禁止横向溢出。
- 操作记录项的主体和右侧元信息列允许收缩，长对象 ID 使用省略显示。
- 移除桌面端固定 480px 容器规则，避免 iPhone 被误判后出现内容裁切。

## 2026-09-04 我的页面（阶段六）

- 新增独立 `ProfilePage.vue`，替换 `/profile` 占位页。
- 展示当前账号、当前工作区和当前角色。
- 退出登录使用确认弹窗，确认后清理登录态和工作区状态并返回登录页。
- 会话恢复时同步读取服务端返回的用户名。

## 2026-09-07 B1 收口

- 用户已完成真实 iPhone 上的 B1 页面与关键交互验收。
- 清理不再使用的 `PlaceholderPage.vue` 和对应入口引用。
- 程序化危险操作确认统一替换为带业务 `data-ai-id` 的 Teleport Dialog。
- 补齐 B1 完整页面的 `data-ai-id` 注册表、验收记录与自动化验证结果。
- Backend typecheck/test（5/5）/db check、Web typecheck/build 均通过。
- B1 状态更新为完成；下一步进入 B2 Product/UX 设计，不开始 B2 实现。
