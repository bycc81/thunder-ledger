- 后端现有自动化测试覆盖认证与会话；真实 PostgreSQL 环境下的多用户、跨工作区和跨批次隔离仍应在后续 CI/测试数据库中补充集成测试。
- 邀请 token 仍由 API 响应一次性返回；生产环境应在 B5 运维阶段确定安全通知与审计留存方式。
- 构建在当前机器需要提升 Node 堆上限；不影响运行时功能，但 CI 应配置相同内存参数或优化前端构建内存。
