# 产品与 UX 定义：B2 商品资料与图片

## 结论与确认

B2 为当前工作区建立可复用的商品资料入口：用户可浏览、搜索、新建和编辑商品；查看者只能阅读。商品作为底部主导航的独立模块进入，工作区概览保留快捷入口；列表、详情和全屏表单延续现有移动端工作台风格。

已确认的体验包含商品资料、多图、首图、轮播、大图预览和图片管理，作为一个 B2 模块交付。库存批次、数量、成本和库存流水属于后续独立模块，不在本次范围。可运行原型位于 prototype/index.html，不连接真实 API 或对象存储。

## 用户、问题与范围

- 目标用户/角色：当前工作区的 owner、admin、editor 和 viewer。
- 使用场景与触发入口：用户从底部“商品”主导航进入，也可从工作区概览的“商品”快捷入口进入，在当前工作区内维护可被后续库存批次复用的商品基础资料。
- 当前问题：B1 已提供工作区、成员和协作批次边界，但没有统一位置登记、查找或维护商品基础资料。
- 产品目标：让用户在移动端清楚识别当前工作区中的商品资料和封面图片，并以最少字段完成新建、查找和维护。
- 可观察结果：新建商品以封面或无图占位出现在当前工作区列表；关键词可缩小结果；有编辑权限的用户可维护资料和图片；查看者明确处于只读状态。
- 本次定义：商品列表、名称搜索、详情、新建、编辑、多图浏览、设置封面、移除图片，以及加载、空数据、错误、只读和提交中反馈。
- 本次不做：分类、标签、SKU、商品状态、商品删除、库存批次、数量、成本、上架、销售、费用、批次绑定或收益规则。

## 用户流程、规则与场景

### 用户主流程

~~~text
底部“商品”主导航 / 工作区概览“商品”快捷入口 → 商品列表
  ├─ 输入名称关键词 → 查看封面和筛选结果 → 打开商品详情
  ├─ 有编辑权限 → 新建商品 → 添加图片/设置封面 → 保存 → 返回并刷新商品列表
  └─ 有编辑权限 → 商品详情 → 编辑资料或图片 → 保存 → 查看更新结果
~~~

- 正常路径：列表展示当前工作区商品及其第一张图片；列表项打开详情；详情通过轮播查看全部图片；保存成功后以刷新后的事实列表和详情作为结果。
- 主要分支：没有商品时提示使用标题右侧的新建入口；无图商品显示中性占位；搜索无结果时保留关键词并提供清除入口；viewer 可阅读列表、封面和详情，但没有新建、编辑和图片管理入口。
- 危险操作：移除图片只解除商品与图片的关联，不删除底层资源，仍须二次确认。B2 不提供商品删除、作废或批量操作。

### 业务规则与权限

- 商品资料属于当前工作区；用户只可读取其有访问权的当前工作区商品。商品在 B2 不绑定协作批次。
- owner、admin、editor 可新建和编辑；viewer 只读。前端显隐不替代服务端授权。
- 名称必填；描述、参考价和图片可选。参考价为非负金额，最多一位小数。
- 一条商品可有零到五张图片；第一张是列表封面。调整顺序可改变封面；移除第一张时下一张自动补位；没有图片时显示无图占位。
- 详情以轮播展示图片，显示当前序号并支持前后切换；点击当前图打开可切换的全屏大图。
- 图片资源支持添加、上传中、上传失败重试、设置封面、移除、私有签名读取与工作区存储权限；资源复用和底层资源软删除不在本次范围。

### 需求场景

#### Requirement: 当前工作区内可复用的商品资料

系统 SHALL 在当前工作区提供独立商品资料列表，且商品资料在本轮不绑定具体协作批次。

#### Scenario: 浏览当前工作区商品

- **WHEN** 用户从底部“商品”主导航或工作区概览进入商品
- **THEN** 系统展示当前工作区商品列表，并明确当前工作区上下文

#### Requirement: 最小资料维护

系统 SHALL 允许 owner、admin 和 editor 使用名称、描述及参考价新建或编辑商品。

#### Scenario: 名称缺失

- **WHEN** 用户未填写名称就提交表单
- **THEN** 系统阻止提交并在名称字段附近说明名称必填，其他输入保持不变

#### Requirement: 多图和唯一封面

系统 SHALL 允许有编辑权限的用户为商品添加最多五张图片，并固定以第一张图片作为列表封面。

#### Scenario: 图片管理

- **WHEN** editor 添加首张图片、将图片移到第一张或确认移除一张图片
- **THEN** 列表首图、详情轮播和无图状态立即反映新的图片顺序

#### Requirement: 按名称查找和只读体验

系统 SHALL 支持按名称关键词筛选当前工作区商品，并允许 viewer 阅读而不能编辑。

#### Scenario: 搜索无结果或 viewer 打开详情

- **WHEN** 关键词无匹配项，或 viewer 打开商品详情
- **THEN** 系统保留关键词并提供清除入口，或展示只读说明且不显示写入入口

## 页面与交互规格

### 页面地图

~~~text
底部主导航：工作区 ｜ 商品 ｜ 批次 ｜ 我的
  └─ 商品（默认入口；工作区概览保留商品快捷入口）
      └─ 商品列表
          ├─ 搜索名称
          ├─ 新建商品 → 商品表单（添加图片/调整顺序）
          └─ 商品详情
              ├─ 图片轮播图 → 全屏大图预览
              └─ 编辑商品 → 商品表单（管理图片）

工作区概览“管理与记录”
  └─ 操作记录（不属于“我的”）
~~~

### 商品列表

- 核心任务：通过首图识别当前工作区商品、按名称查找商品，并从唯一主操作进入新建。
- 信息层级：紧凑顶栏中的工作区上下文 → 标题与新建 → 名称搜索 → 商品列表或状态反馈 → 四项底部导航（商品高亮）。
- 主操作：标题右侧“新建商品”，仅 owner/admin/editor 可见；空列表不重复提供新建入口。
- 关键控件：当前工作区、搜索与清除、包含首图/无图、名称、描述摘要和参考价的可点击列表项。

### 商品详情

- 核心任务：阅读一条商品资料并轮播全部图片，根据角色判断是否可编辑。
- 信息层级：返回栏 → 名称 → 图片轮播 → 描述 → 参考价 → 只读说明或编辑操作。
- 主操作：编辑商品，仅 owner/admin/editor 可见。
- 无图时显示中性占位；首张或末张禁用不可用方向；返回列表保留搜索关键词和位置。

### 新建/编辑商品

- 核心任务：使用最小字段建立或更新商品资料，并维护图片及其顺序。
- 信息层级：返回栏 → 表单说明 → 名称 → 图片 → 描述 → 参考价 → 固定底部保存。
- 主操作：保存商品；取消或返回是次要操作，存在未保存变更时需要确认。
- 关键字段：名称必填；图片最多五张并支持添加、移到第一张、移除、上传中和失败重试；描述可选；参考价可选且非负、最多一位小数。
- 成功后新建返回列表、编辑返回详情；保存失败保留输入并显示字段或页面错误。

## 状态、响应式与验收

### 状态覆盖

| 状态 | 页面表现 | 可执行操作 |
|---|---|---|
| Loading | 列表显示含首图位置的三行骨架，保留上下文和标题 | 禁用新建、搜索和刷新 |
| Empty | 显示“还没有商品资料”，不重复提供新建按钮 | 有权限者通过标题右侧新建；viewer 阅读说明 |
| 搜索无结果 | 显示“未找到匹配商品”，保留关键词 | 清除或修改关键词 |
| Error | 显示加载失败与重试 | 重试；不清除已有表单输入 |
| 无权限 | 保留可读列表和详情并显示只读说明 | 不显示新建、编辑、保存和图片管理 |
| Disabled | 提交、加载、上传中或达到上限时禁用对应操作 | 等待完成或继续未禁用操作 |
| Success | Toast 说明创建或保存结果 | 查看刷新后的列表或详情 |
| 图片上传中/失败 | 图片网格显示上传状态或失败说明 | 填写其他字段、重试或移除 |
| 图片移除确认 | 明确说明仅移除商品关联 | 确认移除或继续编辑 |

### 响应式与视觉边界

- 目标视口：390×844 与 430×932；内容最大宽度 480px，桌面预览居中，不另做桌面后台布局。
- 顶栏固定为 56px，左右内边距 16px；左侧仅显示一行 ThunderLedger 品牌，右侧显示可截断的当前工作区选择器。页面正文距顶栏 20px，标题、搜索和列表左边缘对齐。
- 单列内容；列表使用相邻 Cell 风格而非卡片墙；表单字段上下排列；保存区固定在底部安全区域上方。
- 所有可点控件高度至少 44px；键盘焦点清晰；全屏表单打开时焦点进入标题或第一个字段。
- 沿用白色表面、浅灰画布、深靛蓝主色 #3657c8、危险色 #b42318；无图使用含“无图”文字的中性占位。不使用渐变、营销 Hero、宽表格或装饰性卡片。
- 后续 Vue 实现复用 MobileShell、NavBar、Search、Cell、Field、Popup/Dialog、Toast 和主题变量；原型不导入框架。
- 原型：prototype/index.html。
