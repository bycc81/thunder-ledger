# 公共下拉多选组件与人员筛选统一

## 目标、范围与风险

风险等级：L1。按用户要求调整已有交易页人员筛选的局部布局，将标签与选择框放在同一行；创建账单页的收款人筛选使用同一公共组件。保持现有选择、确定、重置和取消交互，属于已有页面局部控件替换，无新页面或业务模块，无需 HTML 原型。

公共组件放在 `apps/web/src/components/AppMultiSelect.vue`。组件负责显示和选择，不请求业务接口、不解释筛选语义。两个页面将接口成员转换为 `{ value, label }` 选项，用稳定用户 ID 筛选销售。结算推荐、预览、确认、费用联动和利润分配不作调整。

## 组件契约

- `v-model: string[]`：已经应用的选项值，仅在确定时更新；内部草稿在打开时复制。
- `options: { value: string; label: string; disabled?: boolean }[]`：选项值使用稳定业务 ID，允许同名展示。
- `label`、`placeholder`、`hint`、`emptyText`、`countUnit`：调用页面提供业务文案；标签与选择框横向对齐。
- `disabled`：整体禁用；关闭已展开的菜单，禁止更新。
- `aiId?: string`：根区域 ID；内部使用既有 `-dropdown`、`-trigger`、`-panel`、`-options`、`-option-{value}`、`-reset`、`-apply` 约定。`emptyAiId?` 允许保留页面旧空态 ID。
- 基于 Vant Popover 和 Checkbox，采用带边框选择框、等宽锚定菜单和右侧箭头，不增加页面遮罩；选中后显示名称及人数，超长名称省略。
- 多选人员之间取并集；空选择在调用页面解释为全部。确定应用，重置只清空草稿；点击菜单外或 Escape 取消未确认修改，Escape 和确定后焦点返回选择框。
- 菜单限制高度，选项滚动，重置/确定始终可见；触控区域至少 44px。实例 DOM ID 通过 Vue `useId()` 区分，业务定位 ID 由各调用方提供，不在 CSS 使用。

## 复用规则

当前移动端前端规范增加公共组件说明、用法和复用要求；`AGENTS.md` 增加入口规则。今后同类下拉多选优先使用 `AppMultiSelect`，页面维护业务语义及筛选状态，交互差异在公共组件内扩展。

## 验证计划

- Web typecheck/build；静态 UTF-8、引用和 `git diff --check`。
- 交易页完整回归排序、关键词及人员组合筛选、取消/重置、详情和撤销入口、费用隔离。
- 创建账单页回归筛选前后销售勾选、跨筛选已选笔数、费用联动、返回步骤、实际推荐及预览载荷，不提交确认账单。
- 两页在 390×844、430×932 验证标签横向对齐、菜单宽度和位置、无遮罩、键盘、空态、73 人滚动和定位 ID 唯一性。
- 浏览器使用实际 Web 构建产物和既有真实 Fastify 读取路由，数据库边界替换为合成数据。计划增加公共组件隔离验收，覆盖多实例、禁用和外部 v-model 更新；实际执行限制见验收结果。证据统一存放于本目录被忽略的 `evidence/`。
