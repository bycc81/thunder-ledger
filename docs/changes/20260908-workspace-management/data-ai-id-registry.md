# `data-ai-id` 注册表：工作区管理

| ID | 类型 | 用途 |
|---|---|---|
| `workspace-manage-entry` | 控件 | 从工作区选择菜单进入当前工作区管理页 |
| `workspace-management-page` | 页面根 | 工作区管理页 |
| `workspace-management-info` | 区域 | 名称和当前身份 |
| `workspace-management-name` | 输入框 | 工作区名称 |
| `workspace-management-rename` | 控件 | 保存工作区名称 |
| `workspace-delete-blocked` | 提示 | 有批次时不可删除的说明 |
| `workspace-leave` | 危险操作 | 退出他人创建的工作区 |
| `workspace-delete` | 危险操作 | 删除自己创建的空工作区 |
| `workspace-leave-confirm` | 弹窗 | 退出工作区二次确认 |
| `workspace-delete-confirm` | 弹窗 | 删除工作区二次确认 |
