# 工作区管理：产品与 UX 定义

## 结论与确认

在顶部工作区选择菜单增加“管理工作区”入口，打开独立管理页。创建人可在无批次时删除自己创建的工作区；受邀成员可退出工作区，退出后立即失去该工作区与其批次的访问权。原型位于 `prototype/index.html`，本轮不删除历史记录或批次数据。

## 用户、问题与范围

- 目标用户/角色：工作区创建人、被邀请加入的成员。
- 使用场景与触发入口：在任意页面点击顶部当前工作区，在工作区选择菜单中进入管理。
- 当前问题：用户无法退出误加入的工作区，也无法处理误建且尚未使用的工作区。
- 产品目标：将“删除自己的空工作区”和“退出他人工作区”明确区分，避免误删有业务记录的空间。
- 用户完成任务后的可观察结果：删除的空工作区不再可见；退出的工作区不再可进入；已有批次的工作区不可删除。
- 本次做什么：工作区管理页、退出、删除、改名入口与权限校验。
- 本次不做什么：删除批次后再自动删除工作区；转让创建人；恢复已删除工作区；删除操作记录、批次、商品或采购/销售记录。

## 用户流程、规则与场景

### 用户主流程

~~~text
顶部工作区名称 → 工作区选择菜单 → 管理工作区
  ├─ 我创建的工作区 → 修改名称 / 删除（无批次时）
  └─ 他人邀请的工作区 → 退出工作区 → 确认 → 返回仍可访问的工作区
~~~

### 业务规则与权限

- “创建人”以工作区的创建账号为准，不因拥有 owner/admin 角色而取得删除权。
- 只有创建人可改名或删除；系统管理员也不能删除其他人创建的工作区。
- 工作区只要曾创建过批次就不可删除；“删除工作区”按钮保留但置灰，并直接展示原因。
- 非创建人可退出，但创建人不能退出自己创建的工作区。
- 退出只删除当前用户与该工作区的成员关系；批次、商品、交易和操作记录保留。退出后该账号不能读取该工作区的数据。
- 删除为空间软删除，不物理删除历史记录；删除前必须二次确认。

### 需求场景

#### Requirement: 删除自己的空工作区

系统 SHALL 仅允许工作区创建人删除自己创建且没有批次的工作区。

#### Scenario: 创建人删除空工作区

- **WHEN** 创建人在管理页确认删除一个没有批次的工作区
- **THEN** 该工作区从其工作区列表中消失，并自动切换到其他可访问工作区或空状态。

#### Requirement: 退出他人工作区

系统 SHALL 允许非创建人退出被邀请加入的工作区。

#### Scenario: 受邀成员退出

- **WHEN** 受邀成员确认退出当前工作区
- **THEN** 该成员立即不能进入该工作区或读取其中的批次，历史业务与操作记录不被删除。

#### Requirement: 保护已有批次的工作区

系统 SHALL 阻止删除已存在批次的工作区。

#### Scenario: 创建人管理已有批次的工作区

- **WHEN** 创建人打开包含批次的工作区管理页
- **THEN** 页面说明不能删除原因，且服务端也拒绝删除请求。

## 页面与交互规格

### 页面地图

~~~text
顶部工作区选择
  ├─ 切换工作区
  ├─ 创建工作区
  └─ 管理当前工作区 → 工作区管理页
       ├─ 名称（创建人可修改）
       ├─ 当前身份说明
       └─ 危险操作：退出 / 删除
~~~

### 页面：工作区管理

- 核心任务：查看当前身份并完成改名、退出或删除。
- 进入条件：已登录且拥有当前工作区访问权。
- 离开/下一步：成功后返回工作区首页；退出/删除后回退到其他可用工作区或空状态。
- 信息层级：工作区名称与身份 → 删除限制说明 → 操作按钮。
- 主操作：创建人保存名称；成员退出工作区。
- 次要操作：返回。
- 删除或退出：按钮直接置于页面下方，使用红色样式；确认弹窗显示名称和后果。

#### 线框

~~~text
‹ 工作区管理

基本信息
工作区名称       [小卡合买                  ] [保存]
我的身份         创建人 / 成员

提示
已有 2 个批次，暂时不能删除此工作区。
[删除工作区（不可用）]

[退出工作区] 或 [删除工作区]
~~~

#### 关键字段与控件

| 区域 | 字段/控件 | 控件类型 | 必填/可选 | 校验或说明 |
|---|---|---|---|---|
| 基本信息 | 工作区名称 | 输入框 | 创建人可编辑 | 1–120 字符 |
| 基本信息 | 我的身份 | 只读文本 | 必填 | 展示“创建人”或“成员” |
| 提示 | 批次数量/删除限制 | 说明文本 | 按状态展示 | 有批次时直接说明不能删除原因 |
| 页面操作 | 退出工作区 | 红色按钮 | 非创建人 | 二次确认 |
| 页面操作 | 删除工作区 | 红色按钮 | 创建人 | 有批次时禁用；无批次时二次确认 |

#### 交互与反馈

- 成功：改名提示成功；退出/删除后提示成功并回到可访问工作区。
- 失败：保留当前页面和输入，展示服务端原因。
- 保存/提交中：按钮显示处理中，禁止重复提交。
- 返回、取消：不保存修改，返回工作区首页。
- 弹窗：危险确认弹窗清楚说明“不会删除历史记录”或“已有批次无法删除”。

## 状态、响应式与验收

### 状态覆盖

| 状态 | 页面表现 | 可执行操作 |
|---|---|---|
| Loading | 展示加载中 | 不执行危险操作 |
| Error | 展示加载失败和重试 | 重试、返回 |
| 无权限 | 提示无权管理 | 返回 |
| Disabled | 有批次时展示置灰的删除按钮和不能删除原因 | 只能改名（创建人） |
| Success | Toast 并切换工作区 | 继续使用系统 |

### 响应式与视觉边界

- 移动端：沿用现有单列列表，触控目标至少 44px。
- 复用：`MobileShell.vue`、`DangerConfirmDialog.vue`、工作区选择弹层。
- 视觉方向：退出或删除按钮直接放在页面底部，使用红色文本按钮，不与保存操作并列；不额外使用“危险操作”标题。
- 原型：`prototype/index.html`。

### 页面验收

- [ ] 创建人与受邀成员看到不同的危险操作。
- [ ] 有批次的工作区不能删除。
- [ ] 退出后不能再次访问该工作区。
- [ ] 删除/退出前均有明确二次确认。
- [ ] 原型的关键业务节点已登记稳定 data-ai-id。
