# B4.1 测试计划

- 采购无销售直接编辑；有销售更正必须填写原因；有报损时拒绝更正。
- 两笔采购在销售前时按移动平均成本扣减；后发生采购不影响此前销售；时间倒序导致历史负库存时拒绝保存。
- 更正数量、金额、付款人、成本承担后，未结算销售预览成本及成员净额更新。
- 结算计算：成本承担由采购成本流水自动汇总，不发送 `costShares`；销售额 500、商品成本 126、利润 50%/50%，采购成本承担 admin 126、dandan 0 时，利润各 187，转账建议为 dandan 向 admin 转 313。
- 结算页面不提供成本承担输入；采购更正后，未结算销售的自动成本承担和结算预览随流水更新。
- 已确认账单不变；每次更正创建每账单一张调整单，多次更正不覆盖已有调整单。
- 未授权、重复确认、并发更正被拒绝；确认后调整单只读。
- 运行后端 typecheck/test/db:check，前端 typecheck/build；在两个移动视口人工验收关键流程和 data-ai-id。
- 采购页面只展示一个“采购时间”；有销售时商品、采购渠道和采购时间直接禁用。
- 仅修改备注等非成本字段时不重放成本流水；有报损/丢失时页面禁用提交且接口拒绝更正。
- 跨日期的采购与销售按时间戳排序，不受日期字符串/星期文本影响；时间线错误必须指出具体时间、记录类型、需要数量和当时库存。
- 数量更正按商品整体时间流水校验：某条采购可少于全部累计销售，只要各销售时点库存不为负；后发生采购不能支撑更早销售。
- 销售保存后无编辑/改时间接口；采购更正不会改变销售成交时间。
- 验收销售列表无“编辑/改成交时间”入口，采购更正前后销售成交时间保持不变。
