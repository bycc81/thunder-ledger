# B4.1 采购更正与结算调整单

## 已确认规则

- 无销售记录的采购可直接编辑；实际新增到货使用“新增采购”，并可通过“复制采购”预填字段。
- 有销售记录后，编辑采购即为“更正原采购”。采购主记录显示最新值，系统保留不可编辑的更正历史。
- 采购页面只使用一个“采购时间”字段；数据库兼容字段由采购时间派生，不在页面展示或提交。
- 有销售后进入“更正采购”态，只允许数量、总金额、实际付款人和成本承担；商品、渠道、采购时间直接禁用。
- 数量更正不要求本条采购单独覆盖全部销售；只要按商品时间流水重放后，每笔销售发生时的累计库存都不为负即可。
- 销售成交时间在保存时确定，保存后不提供修改入口；采购更正只重算成本，不改写销售时间。
- 销售录入页将“成交时间”作为必填的最终时间；销售保存后只允许按现有撤销流程处理，不提供修改成交时间的操作。
- 存在报损或丢失减库存记录时，不允许更正该商品的采购。
- 销售成本按发生时间的商品移动平均成本计算；结算直接使用成本流水重放后的销售快照，不以当前库存总成本回算历史销售。
- 已确认账单保持原样。每次更正对每张受影响账单创建一张待确认结算调整单；用户在结算模块逐张确认。
- 同一种商品不追踪到具体采购记录。采购、销售和报损按精确发生时间构成商品成本流水，使用移动加权平均成本；采购发生在销售之后不会反向影响此前销售。
- 采购成本承担随库存成本一同按平均法扣减，结算只展示自动汇总结果，不再手工覆盖。
- 采购记录是成本承担与实际付款人的唯一事实来源；结算页不再填写或修改成本承担。
- 结算页只允许填写本次利润比例，成本承担区域以只读方式展示系统按成本流水自动汇总的结果。
- 如需改变成本承担或付款人，必须回到采购记录执行更正；结算中不提供临时覆盖。

## 页面与状态

- 采购编辑页在存在销售时显示“更正采购”提示、原因输入和保存确认；保存后提示已生成的调整单数量。
- 采购记录可使用“复制采购”进入新增表单，不复制库存消耗和历史。
- 结算首页在已确认账单前展示待处理调整单；原账单详情展示关联调整单。
- 调整单详情展示原值到更正后成本、成员应收应付差额和转账建议；确认后只读。

## 验收

在 390×844 与 430×932 视口完成采购更正、查看调整单、逐张确认三个流程，无横向溢出或遮挡。
