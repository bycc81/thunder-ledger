# 商品组与款式 Product/UX

## 目标

用一个对外商品组承载多个成员/封面款式；采购、库存、销售和结算仍按底层独立商品记录。

## 主流程

商品组创建（款式可选）→ 可通过“快捷生成商品组”选择组合模板并生成款式与逐款参考价 → 保存后从商品列表选择批次进入采购 → 销售时选择商品或款式 → 结算按销售单展示商品组·款式。

无款式商品沿用现有流程。

## 业务规则

- 商品组可没有款式；无款式商品直接采购与销售。款式名在商品组内唯一；款式库存和成本彼此独立。
- 商品组保存只创建商品资料；采购从商品列表选择开放批次后进入。上架记录不属于当前私人账务主流程。
- 采购页以单价和数量计算款式金额，所有款式金额自动汇总为采购总金额；“按数量均摊总成本”可按数量反算单价。成本承担合计必须等于采购总金额。
- 组合模板是工作区内可复用的款式清单。套用模板会复制款式，之后可独立增删改；修改或删除模板不影响既有商品组和账务。
- 款式可填写独立参考价；参考价只用于商品资料展示，不参与采购成本、销售成交价或结算。
- 销售提交底层 productId；商品组和款式名称保存快照用于历史展示。
- 商品组、款式、上架和销售写入仅限 owner/admin/editor；viewer 只读。
- 不改既有成本、手续费、利润和结算转账公式。

## 页面与验收

- 商品组创建页显示公共资料与可选款式列表；“快捷生成商品组”打开“选择组合模板”选择器。每个款式可填写独立参考价；采购数量与单价只在进入批次后的现有“新增采购”页填写。
- 组合模板管理页支持新建、编辑和删除模板；删除操作二次确认，并明确不影响既有商品组和账务。
- 商品组采购页逐款显示“款式、数量、单价、款式总额”，并显示自动汇总的“采购总金额”；采购完成直接返回库存页。
- 创建页仅提供“保存商品组”。
- 销售表单商品组选择后联动款式和可售数量。
- 销售列表、结算草稿、结算账单显示“商品组 · 款式”。
