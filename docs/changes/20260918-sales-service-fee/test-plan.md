# 销售手续费与金额精度：测试计划

## 验收场景

- 成交 `99.99`、比例 `1.60%` 时手续费为 `1.60`，实际收款为 `98.39`。
- 可选渠道可单独保存；未填写手续费时手续费为 `0.00`。
- 金额和比例最多两位小数；手续费金额超过成交额、比例超过 100 均被拒绝。
- 结算利润和卖出人收款均扣除手续费；报表和 CSV 显示手续费及实际收款。
- 既有数据迁移后展示金额不变，内部值为原值 ×10。

## 自动验证

- `apps/backend`: `npm.cmd run typecheck`、`npm.cmd test`、`npm.cmd run db:check`
- `apps/web`: `npm.cmd run typecheck`、`npm.cmd run build`
