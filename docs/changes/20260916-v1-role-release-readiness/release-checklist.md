## 回滚执行顺序

1. 任一健康、权限、Cookie、R2、金额或迁移检查失败，立即停止继续发布和业务写入。
2. Render 与 Pages 回退到上一可用部署，恢复发布前保存的环境变量版本。
3. 数据库迁移不自动反向执行；如数据受到影响，使用发布前 Neon 备份恢复到隔离分支或项目，核对迁移和核心数据后再切换 `DATABASE_URL`。
4. 回退后重新检查健康接口、登录会话、核心业务闭环、报表和 CSV，再决定是否恢复服务。

## 停止条件

出现健康检查失败、权限越权、迁移异常、Cookie 无法恢复、R2 失败或核心金额不一致时，停止发布并回退到上一可用版本。
