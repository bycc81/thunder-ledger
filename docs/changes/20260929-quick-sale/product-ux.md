# 快速售出（Quick Sale）产品与 UX 定义

- 日期：2026-09-29
- 变更目录：`docs/changes/20260929-quick-sale/`
- 风险等级：L2（新增数据库表、扩展成本账本、扩展结算可用项）

## 1. 用户与问题

个人/小团队经营者在批次内售出商品时，以下场景现有"记录销售"操作繁琐：

- 库存只剩 1 件的商品，仍需先建商品、再逐笔录入。
- 组合出售（例如"专辑 + 小卡"set）时，需要分别录两次销售，钱要拆、操作复杂。
- 卖出没有库存记录的商品（例如转卖二手、无采购记录），无法便捷录入。

现状：现有销售为单商品、必须引用已建商品、必然扣减库存并校验可用量。

## 2. 目标

一次录入一笔快速售出：

- 商品行可自由填写名称，可一次录入多行。
- 每行可选"关联库存"：多选本批次有库存的商品，每项带计数器（默认 1、下限 1、上限为该项剩余库存），可单项删除。
- 整单一个成交总价（不分到行），同时每行支持成本；成本始终可输入，可点“按库存成本”按钮按已关联库存的单位成本合计快速填充（须先关联库存）。
- 保存后扣减关联库存、消耗成本，并作为可结算项进入阶段账单，与普通销售走同一结算流程。

## 3. 范围

包含：

- 快速售出创建、列表、详情、撤销。
- 关联库存扣减与成本消耗（扩展成本账本事件源）。
- 快速售出参与结算（阶段账单可用项、快照、利润与成员分配）。

不包含：

- 修改既有销售/上架/采购流程与数据。
- 自动创建商品（商品名自由填写，仅保存快照；关联库存时引用已有商品）。
- 批量导入、订单同步等外部系统对接。

## 4. 主流程

1. 批次交易页或批次详情进入"快速售出"表单。
2. 填写整单：成交总价（必填）、卖出人（必填）、成交时间（默认当前，保存后不可改）、销售渠道（可选）、手续费（可选，规则同现有销售）、备注（可选）。
3. 添加商品行：
   - 商品名：自由输入，可搜索选择已有商品以带出名称/库存参考。
   - 售出数量：默认 1。
   - 成本：始终可编辑，输入优先；“按库存成本”按钮仅在“已开启关联库存 + 已选择关联数据 + 关联数量 ≥ 1”三条件同时满足时可用，否则置灰；带出值 = 关联库存单位成本合计 × 售出数量；留空为 0。
   - 关联库存：开关；开启后多选本批次有库存的商品，每项显示商品名与可用库存，计数器默认 1、下限 1、上限为该项剩余库存，可单项删除。
4. 保存：后端在事务内校验各商品行关联数量总和 ≤ 该商品当时可用库存，扣减库存、回填成本，生成快速售出单。
5. 单据进入"快速售出"列表，并作为未结账可用项出现在结算草稿中。
6. 可撤销：填原因后撤销，关联库存恢复、成本回退；已纳入账单的快速售出不可撤销（409）。

## 5. 关键边界与规则

- 关联库存商品必须属于当前批次、有采购记录且当前剩余可卖；关联数量取值范围 1 到该商品当时可用数量。\n- 系统不自动修改用户填写的售出数量与关联数量；若某商品行售出数量与任一关联库存数量不一致，保存时弹出二次确认框，用户可“取消”返回修改，或“确认”继续保存，系统不更改填写值。
- 同一库存商品可在多个商品行中被关联，保存时校验总关联量不超过当时可用库存。
- 未关联库存的行不扣任何库存；该行成本来自界面输入或“带入成本”（默认 0）。
- 整单成交总价 ≥ 0；本单成本 ≥ 0；手续费校验与现有销售一致（比例或固定金额，实收 ≥ 0）。
- 撤销采用独立表 `quick_sale_reversals`，原记录不删除；已结算的快速售出禁止撤销。\n- 所有删除与撤销操作必须先二次确认；删除按钮使用图标（垃圾桶/移除），行内快捷操作与字段旁操作为紧凑 36px、次级操作为 40px、保存/确认/危险操作为 44px，遵循前端按钮规范（`docs/changes/20260922-button-sizing`）。
- 结算：快速售出作为未结算可用项进入阶段账单，草稿中与普通销售并列勾选、计算逻辑一致，不因来源不同而区分；利润 = 成交总价 - 服务费 - 本单成本 - 关联费用，本单成本按界面输入/带入值计入；关联库存的库存账成本消耗仍由成本账本按库存成本内部计算（保证库存成本不悬空），在自定义成本场景可与界面成本不同，属预期；展示处带“快速售出”来源标识。
- 权限：读取沿用批次可读（owner/editor/viewer）；创建与撤销沿用批次可编辑（owner/editor）。
- 快速售出不影响既有 sales、listings、purchase、settlement 的任何数据与逻辑；结算草稿展示层将两种来源统一列出。

## 6. 页面与导航

- `QuickSaleFormPage`：`/batches/:id/quick-sales/new`
- `QuickSaleDetailPage`：`/batches/:id/quick-sales/:quickSaleId`
- 列表：并入批次交易页（新增"快速售出"入口与 Tab），不新建独立主导航。
- 入口：批次详情与交易页新增"快速售出"按钮。
- 结算草稿页：未结账快速售出与普通销售并列展示、同样勾选与计算（不区分来源），列表项带“快速售出”来源标识。

## 7. 验收

- 移动端常用视口截图（表单、详情、结算草稿含快速售出）。
- 关键交互逐项验证：商品行增删、关联库存多选、计数器增减（1..可用库存）、单项删除、保存、撤销、已结算撤销拦截；所有删除/撤销均触发二次确认；售出数量与关联数量不一致时保存弹出二次确认，可取消修改或确认保存。
- `data-ai-id` 扫描与注册表一致（见 `data-ai-id-registry.md`）。
- 后端 `npm run typecheck`、`npm test`；前端 `npm run typecheck`、`npm run build`；迁移 `npm run db:check`。
- 专项验证：时间线库存扣减、库存不足 409、撤销恢复、结算利润、既有销售结算回归。
