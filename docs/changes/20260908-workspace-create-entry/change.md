# 工作区创建入口

## 变更说明

- 目标：让首次登录且没有工作区的用户，能够直接在页面创建第一个工作区。
- 影响范围：工作区空状态、顶部工作区选择弹层及工作区状态管理。
- 非目标：不自动为已有线上账号补建个人空间；不修改工作区权限、成员、批次或数据库结构。
- 风险等级：L1。复用已有 `POST /api/workspaces`，仅新增前端入口和状态更新。

## 验收

1. 没有工作区时，工作区首页展示“创建工作区”。
2. 任意页面从顶部工作区选择中可进入创建工作区。
3. 仅填写名称即可创建协作工作区；创建人自动成为负责人，且新空间自动切换为当前工作区。
4. 创建失败时保留在页面并展示失败提示；已有工作区切换不受影响。
