# `data-ai-id` 注册表：工作区创建入口

| ID | 类型 | 用途 |
|---|---|---|
| `workspace-empty` | 空状态区域 | 当前账号没有工作区时的说明与操作区 |
| `workspace-empty-create` | 控件 | 空状态下打开创建工作区弹窗 |
| `workspace-picker` | 弹层 | 顶部工作区选择弹层 |
| `workspace-create-entry` | 控件 | 从工作区选择弹层打开创建弹窗 |
| `workspace-create-dialog` | 弹窗 | 创建工作区弹窗根节点 |
| `workspace-create-name` | 输入框 | 工作区名称 |
