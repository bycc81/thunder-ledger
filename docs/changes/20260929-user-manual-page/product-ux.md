# 站内使用手册页面产品与 UX 定义

## 结论与确认

将现有 Markdown 使用手册转为登录后可访问的站内移动端页面，路由为 `/help/user-manual`。页面以“先选对操作”为首屏入口，覆盖工作区、批次、商品、采购、交易和结算；入口固定放在“我的”页的“帮助与支持”区，不接入业务数据或新增后端接口。

原型位于 [prototype/index.html](prototype/index.html)。页面结构、信息层级和折叠交互已确认，按此建立页面/API 契约并实现 Vue 路由。

## 用户、问题与范围

- 目标用户/角色：已登录的工作区成员，尤其是首次录入采购、销售或结算的成员。
- 使用场景与触发入口：用户在“我的”页点击“使用手册”，或通过服务访问 `/help/user-manual`，查找某项操作该从哪里开始、会影响什么数据。
- 当前问题：Markdown 手册不适合在手机上快速定位；快速售出与普通销售的适用边界不够直观。
- 产品目标：用户在一个移动端页面内，能选对工作区、批次、商品、库存、交易和结算入口，理解两类销售差异，并查到关键规则。
- 用户完成任务后的可观察结果：用户能从“我想做什么”进入相应说明，展开需要的步骤并据此完成业务操作。
- 本次做什么：建立静态、可读、可折叠的站内手册页面；内容复用 `docs/user-manual.md` 的已确认规则。
- 本次不做什么：不新增业务数据、搜索、反馈收集、在线编辑、下载、后端 API 或底部导航入口。

## 用户流程、规则与场景

### 用户主流程

```text
我的 → 使用手册 → 查看“先选对操作” → 打开对应操作章节
→ 阅读步骤与关键规则 → 返回实际业务页面完成操作
```

### 业务规则与权限

- 角色和可见范围：页面路由要求已登录；所有已登录用户可阅读相同手册内容。
- 可执行操作：锚点跳转、展开/收起常见问题和规则说明、返回上一页。
- 状态和状态转换：页面为静态内容，无加载、保存或业务状态。
- 不可破坏的业务规则：页面说明必须与 `docs/user-manual.md` 和已实现的快速售出、库存、费用、结算规则一致；不得用页面文案改变业务口径。

### 需求场景

#### Requirement: 操作选择

系统 SHALL 在首屏展示采购、普通销售、快速售出、费用和结算的操作选择，帮助用户选择正确入口。

#### Scenario: 用户要卖出多个商品

- **WHEN** 用户在“先选对操作”看到“一次卖多件、组合售出或不建商品直接卖”
- **THEN** 系统展示“快速售出”入口说明，并可跳转到快速售出章节。

#### Requirement: 系统内入口与基础模块说明

系统 SHALL 在“我的”页提供使用手册入口，并在手册中说明工作区、批次和商品的用途与关系。

#### Scenario: 新成员了解业务结构

- **WHEN** 用户点击“我的”页的“使用手册”
- **THEN** 系统打开手册，用户可从首屏跳转至工作区、批次或商品说明。

#### Requirement: 快速售出说明

系统 SHALL 明确快速售出的多商品项、本单成本、关联库存、库存影响和结算口径。

#### Scenario: 用户不关联库存快速售出

- **WHEN** 用户展开“快速售出”章节
- **THEN** 系统说明仍需填写商品名、数量、本单成本、成交总价和卖出人，但不扣库存也不创建商品。

#### Requirement: 快速定位

系统 SHALL 提供章节导航和可折叠常见问题，避免用户在移动端阅读长篇文字。

#### Scenario: 用户要确认是否能撤销

- **WHEN** 用户点击“能撤销已结账交易吗？”
- **THEN** 系统展开答案，说明已结账交易不能直接撤销，应按结算调整流程处理。

## 页面与交互规格

### 页面地图

```text
/help/user-manual
  ├─ 顶部导航与返回
  ├─ 先选对操作
  ├─ 工作区、批次与商品
  ├─ 销售方式对照
  ├─ 快速售出重点规则
  ├─ 库存、费用与结算
  └─ 常见问题（折叠）
```

### 页面：站内使用手册

- 核心任务：快速找到正确业务操作和不可忽略的规则。
- 进入条件：已登录。
- 离开/下一步：顶部返回上一页；章节链接在当前页锚点跳转。
- 信息层级：先操作选择，再工作区/批次/商品、销售对照和快速售出，最后是库存/结算与 FAQ。
- 主操作：点击操作选择卡跳转对应章节。
- 次要操作：章节导航、展开 FAQ。
- 危险操作与确认：无。

#### 线框

```text
[返回]                 使用手册
[先选对操作]
[工作区] [批次] [商品] [采购] [普通销售] [快速售出] [费用] [结算]

[工作区、批次与商品]

[普通销售]             [快速售出]
适用场景与库存影响对照

[快速售出重点规则]
本单成本 / 关联库存 / 数量不一致确认

[库存、费用与结算]
[常见问题 ▾]
```

#### 关键字段与控件

| 区域 | 字段/控件 | 控件类型 | 必填/可选 | 校验或说明 |
| --- | --- | --- | --- | --- |
| 顶部 | 返回 | 按钮 | 可选 | 返回来源页；无来源时回到工作区。 |
| 操作选择 | 工作区、批次、商品、采购、普通销售、快速售出、费用、结算 | 锚点按钮 | 可选 | 每项跳到当前页对应章节。 |
| 销售对照 | 普通销售、快速售出 | 静态对照表 | 无 | 说明适用场景、库存影响和结算成本。 |
| FAQ | 问题与答案 | `details/summary` | 可选 | 同时可展开多项，不保留状态。 |

#### 交互与反馈

- 成功：锚点平滑滚动至对应章节；FAQ 展开答案。
- 失败：无请求，不产生失败状态。
- 保存/提交中：无。
- 返回、取消和未保存变更：无未保存内容；返回上一页。
- 弹窗、抽屉、跳转：无弹窗；仅页内锚点与返回跳转。

## 状态、响应式与验收

### 状态覆盖

| 状态 | 页面表现 | 可执行操作 |
| --- | --- | --- |
| Loading | 无远端数据，首次渲染后直接展示静态内容。 | 无 |
| Empty | 不适用，始终有固定手册内容。 | 无 |
| Error | 不适用，无请求。 | 返回 |
| 无权限 | 未登录时由现有路由守卫跳转登录页。 | 登录 |
| Disabled | 不适用。 | 无 |
| Success | 章节可读、导航与 FAQ 正常工作。 | 锚点跳转、展开 FAQ |

### 响应式与视觉边界

- 桌面端：内容最大宽度与现有移动端容器一致，不维护独立桌面信息架构。
- 移动端：以 390×844 和 430×932 为验收视口；操作选择使用单列列表，避免卡片墙。
- 键盘焦点和触控目标：返回、章节跳转和 FAQ 摘要最小触控高度 44px，显示焦点轮廓。
- 复用的现有页面/组件：Vant `NavBar`、现有全局色彩和间距；不新增 UI 库。
- 视觉方向与禁止模式：清晰列表和说明块，不使用渐变、营销 Hero 或大面积装饰背景。
- 原型：`prototype/index.html`。

### 页面验收

- [ ] 用户可从“我的”页进入使用手册。
- [ ] 用户能在首屏选中工作区、批次、商品、采购、普通销售、快速售出、费用或结算。
- [ ] 普通销售和快速售出的适用场景、库存影响和结算成本区别清晰。
- [ ] 快速售出的本单成本必填可为 0、关联库存多选、数量不一致确认均可查到。
- [ ] FAQ 可展开，移动端无横向溢出。
- [ ] 原型关键节点已登记稳定 `data-ai-id`。
- [x] 用户已直接打开原型确认页面结构、主流程和关键交互。
