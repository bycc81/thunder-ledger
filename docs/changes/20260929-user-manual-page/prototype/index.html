普通销售还是快速售出？

普通销售

一个已有库存商品

  • 选择商品和数量，数量不能超过可卖库存。
  • 保存后扣减该商品库存。
  • 结算成本按库存成本计算。
快速售出

一次卖多件或自由录入

  • 可添加多个商品项，商品名自由填写。
  • 每项可不关联库存，也可多选关联库存。
  • 结算成本以每项填写的本单成本为准。

快速售出重点

1
本单成本必须填写

每个商品项都要填写本单成本；可以填 0，但不能留空。

2
关联库存可多选

开启关联库存后，可添加多个已有库存商品，并分别填写关联数量。

3
只扣被关联的库存

未关联库存的商品项不会扣库存，也不会自动创建商品或采购记录。

4
数量不一致需要确认

售出数量和关联库存数量可以不同；保存前会提示确认，系统不会自动改数。

快速售出详情会同时显示“本单成本”和“库存账消耗成本”：结算使用本单成本，库存账成本用于维护剩余库存成本。

采购、费用与结算

购
采购形成库存

总成本允许为 0；成本承担合计必须等于总成本。

费
费用最多关联一种交易

费用可关联普通销售或快速售出；关联后会随该交易自动进入结算。

结
结算会同时纳入两类销售

勾选普通销售和快速售出，确认利润比例后生成锁定的阶段账单。

常见问题

快速售出不关联库存可以吗？

可以。仍需填写商品名、数量、本单成本、成交总价和卖出人；不会扣库存，也不会创建商品。

为什么普通销售里的可卖数量变少了？

除普通销售和损坏/丢失外，已关联库存的未撤销快速售出也会占用并扣减可卖库存。

能撤销已结账交易吗？

不能。已结账交易不能直接撤销，需要通过既有的结算调整流程处理。
