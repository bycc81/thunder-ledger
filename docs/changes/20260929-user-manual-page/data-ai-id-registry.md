# 站内使用手册 data-ai-id 注册表

| data-ai-id | 元素 |
| --- | --- |
| user-manual-page | 页面根节点 |
| user-manual-topbar | 顶部导航 |
| user-manual-back | 返回按钮 |
| user-manual-task-nav | “先选对操作”导航区 |
| user-manual-task-workspace | 跳转工作区章节 |
| user-manual-task-batch | 跳转批次章节 |
| user-manual-task-product | 跳转商品章节 |
| user-manual-task-purchase | 跳转采购章节 |
| user-manual-task-sale | 跳转普通销售章节 |
| user-manual-task-quick-sale | 跳转快速售出章节 |
| user-manual-task-expense | 跳转费用章节 |
| user-manual-task-settlement | 跳转结算章节 |
| user-manual-sale-compare | 普通销售与快速售出对照区 |
| user-manual-workspace-batch-product | 工作区、批次与商品说明区 |
| user-manual-quick-sale | 快速售出说明区 |
| user-manual-inventory-settlement | 库存、费用与结算说明区 |
| user-manual-faq | 常见问题区 |
| user-manual-faq-{topic} | 常见问题折叠项；`{topic}` 为固定语义，如 `quick-sale-cost` |
| profile-help-section | “我的”页帮助与支持区 |
| user-manual-entry | 从“我的”页进入使用手册 |
