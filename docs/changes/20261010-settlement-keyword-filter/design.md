# 创建账单销售关键词筛选

## 目标、范围与风险

风险等级：L1。已有创建账单页的第 1 步增加商品名称关键词搜索，与收款人多选筛选组合，方便定位待结算的普通销售与快速售出。沿用交易页搜索样式和公共人员多选组件，属于已有页面局部控件增加，无需新页面原型。

范围：`SettlementCreatePage.vue` 的本地展示过滤、验证脚本、定位注册表与使用手册。不改接口、权限、收益计算、费用联动、账单确认或数据库。

## 筛选与选择契约

- 收款人筛选上方增加 Vant Search，实时包含匹配商品名称、展示名、商品组和款式；普通销售与快速售出均适用。
- 忽略关键词首尾空白，不区分大小写；空白输入显示当前人员条件下的全部销售。
- 关键词与人员取交集，多个人员之间取并集，未选择人员时为全部人员。关键词条件仅影响销售列表，不过滤费用。
- 保持原选择契约：筛选不取消任何已勾选销售；全选/清空仅作用于当前可见结果；显示筛选外已选笔数；隐藏已选销售及其关联费用仍进入推荐/预览请求。
- 无匹配提示“当前筛选条件下暂无待结算销售”，禁用全选；不影响已经选择的销售进入下一步。返回第 1 步保留关键词、人员和勾选状态。
- 搜索框根包装使用稳定的 `settlement-product-keyword`，避免 Vant Search 将属性透传造成重复 ID。筛选区域新增 `settlement-sale-filters`，原人员及销售 ID 保持。
