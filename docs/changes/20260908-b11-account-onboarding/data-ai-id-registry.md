# `data-ai-id` 注册表：B1.1 注册与账号管理

| ID | 类型 | 用途 |
|---|---|---|
| `register-page` | 页面根 | 受邀注册链接页 |
| `register-invitation` | 区域 | 邀请链接状态与用户名 |
| `register-username` | 输入框 | 只读展示邀请用户名 |
| `register-password` | 输入框 | 设置密码 |
| `register-password-confirm` | 输入框 | 再次输入密码 |
| `register-submit` | 控件 | 完成注册 |
| `register-login-link` | 控件 | 返回登录 |
| `member-add` | 控件 | 打开添加成员弹窗 |
| `member-invite-dialog` | 弹窗 | 添加成员弹窗根；沿用既有稳定 ID |
| `member-add-mode` | 选择器 | 选择邀请新账号或加入已有账号 |
| `member-add-username` | 输入框 | 输入用户名 |
| `member-invite-role` | 选择器 | 选择工作区角色；沿用既有稳定 ID |
| `member-add-submit` | 控件 | 提交添加成员 |
| `member-invitation-link` | 区域 | 一次性展示注册链接 |
| `member-invite-token` | 文本框 | 可选择、可长按复制的注册链接 |
| `member-invitation-link-copy` | 控件 | 复制注册链接 |
| `member-invitation-link-open` | 控件 | 不依赖剪贴板直接打开注册链接 |
| `member-invitation-close` | 控件 | 关闭已生成链接的弹窗 |
| `member-invite-cancel` | 控件 | 取消添加成员 |
| `profile-password-change` | 控件 | 打开本人修改密码弹窗 |
| `password-change-dialog` | 弹窗 | 修改本人密码弹窗根 |
| `password-current` | 输入框 | 输入当前密码 |
| `password-new` | 输入框 | 输入新密码 |
| `password-confirm` | 输入框 | 再次输入新密码 |
| `password-change-submit` | 控件 | 保存新密码 |
| `account-management-entry` | 控件 | 打开系统账号管理 |
| `account-management-page` | 页面根 | 系统账号管理页 |
| `account-list` | 区域 | 账号列表 |
| `account-item-{accountId}` | 列表项 | 指定账号 |
| `account-create` | 控件 | 打开开通账号弹窗 |
| `account-create-dialog` | 弹窗 | 开通账号弹窗根 |
| `account-create-username` | 输入框 | 设置用户名 |
| `account-create-password` | 输入框 | 设置初始密码 |
| `account-create-password-confirm` | 输入框 | 再次输入初始密码 |
| `account-create-submit` | 控件 | 开通账号 |
| `account-actions-{accountId}` | 控件 | 打开指定账号更多操作 |
| `account-status-{accountId}` | 控件 | 直接停用或恢复指定普通账号 |
| `account-status-confirm` | 弹窗 | 停用或恢复账号确认 |
| `account-password-reset` | 弹窗 | 重置指定账号密码弹窗根 |
| `account-password-reset-input` | 输入框 | 设置重置后的密码 |
| `account-password-reset-confirm` | 输入框 | 再次输入重置后的密码 |
| `account-password-reset-submit` | 控件 | 提交密码重置 |
