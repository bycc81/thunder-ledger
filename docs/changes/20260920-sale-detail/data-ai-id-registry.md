# 销售详情 `data-ai-id` 注册表

| `data-ai-id` | 类型 | 用途 |
|---|---|---|
| `sale-item-{saleId}` | 列表项 | 交易页中打开指定销售详情；沿用既有 ID |
| `sale-detail-page` | 页面根节点 | 销售详情页面定位 |
| `sale-detail-topbar` | 顶部导航 | 返回交易列表 |
| `sale-detail-summary` | 区域 | 商品、数量、状态和成交总价摘要 |
| `sale-detail-status` | 状态 | 待结账、已结账或已撤销状态 |
| `sale-detail-payment` | 区域 | 成交总价、手续费、实际收款和卖出人 |
| `sale-detail-cost` | 区域 | 销售成本与销售毛利 |
| `sale-detail-expenses` | 列表 | 关联其他费用 |
| `sale-detail-expense-{expenseId}` | 列表项 | 指定关联其他费用 |
| `sale-detail-note` | 区域 | 销售备注 |
| `sale-detail-reversal` | 区域 | 撤销原因和撤销时间 |
| `sale-detail-settlement` | 区域 | 结账归属与账单入口 |
| `sale-detail-settlement-open` | 控件 | 打开所属已确认账单 |
| `sale-detail-loading` | 状态 | 详情加载中 |
| `sale-detail-error` | 状态 | 详情加载失败 |
| `sale-detail-retry` | 控件 | 重试详情查询 |
| `sale-detail-not-found` | 状态 | 销售不存在或无读取权限 |
