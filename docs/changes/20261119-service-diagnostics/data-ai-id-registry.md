# 服务连接诊断定位注册表

原有登录页及唤醒 ID 沿用 [既有注册表](../20261112-login-service-wakeup/data-ai-id-registry.md)。

| data-ai-id | 用途 |
| --- | --- |
| login-service-diagnostics | 可展开的诊断区域 |
| login-service-diagnostics-toggle | 展开与收起诊断 |
| login-service-diagnostics-summary | 最近请求结论 |
| login-service-diagnostics-copy | 复制诊断信息 |
| login-service-diagnostics-clear | 清除本机记录 |
| login-service-diagnostics-feedback | 复制/清除结果 |
| login-service-diagnostics-report | 可手动选择的只读报告 |
| login-service-health-link | 按网站当前 API 配置打开健康检查 |
| login-service-origin-health-link | 在浏览器直连 Render 健康检查 |
