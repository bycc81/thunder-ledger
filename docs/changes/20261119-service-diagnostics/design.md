# 手机端服务连接诊断

- 风险：L1，仅补充现有登录页连接恢复区域及只读请求诊断；不改变认证、权限、代理、安全策略或部署。
- 目标：手机无需开发者工具即可区分 Render 唤醒限流、其他 HTTP 错误、超时和响应异常；恢复后仍能留存故障证据。
- 范围：现有唤醒按钮、状态提示及其下方可展开的诊断信息；无新页面，不改变登录主流程。沿用现有 4 次重试及 Retry-After 等待，不承诺绕过平台限制。
- 页面/API 契约：被动记录 GET `/healthz`、`/auth/captcha`、`/auth/session` 的时间、耗时、HTTP 状态和白名单响应头；200 必须符合对应 JSON 结构才算正常。会话 401 标记为正常未登录。不采集登录请求、请求头、响应体、用户名、密码、验证码、Cookie 或 Token。
- 记录：本机浏览器 localStorage 保存最近 24 小时最多 30 条，刷新页面、服务恢复后保留；存储不可用时退化为本页内存。读取缓存时只恢复白名单字段。用户可复制、手动全选或清除。
- 交互：不增加自动轮询；展开诊断不发请求。提供当前 API 健康检查和当前 Render 后端直连健康检查链接（新标签打开，直连仅人工观察，避免跨域读取结果被误判）；直连域名来自现有代理源码中的正式地址，后端迁移时须同步更新。
- 定位：保留原 ID，新增 ID 见本目录 `data-ai-id-registry.md`。
- 验收：Web typecheck/build；390×844、430×932 截图、交互与 ID；429 来源识别、恢复后历史保留、刷新持久化、超时/网络/HTML 响应识别、复制失败手动选择、清除、无凭据及响应体泄漏、原唤醒重试边界回归。
- 回滚：撤销此次前端及文档改动；无数据迁移及生产操作。
