# 商品删除 data-ai-id 注册表

| data-ai-id | 元素 | 说明 |
| --- | --- | --- |
| product-more-actions | 商品详情更多操作按钮 | 打开低频操作菜单，仅 workspace 可编辑角色显示 |
| product-more-actions-sheet | 商品详情更多操作菜单 | 仅在菜单内显示删除商品危险操作 |
| product-delete | 商品详情删除菜单项 | 危险操作，仅 workspace 可编辑角色显示 |
| product-delete-confirm-dialog | 删除商品确认弹窗 | 取消不删除，确认调用删除接口 |
| product-group-more-actions | 商品组详情更多操作按钮 | 打开低频操作菜单，仅 workspace 可编辑角色显示 |
| product-group-more-actions-sheet | 商品组详情更多操作菜单 | 仅在菜单内显示删除商品组危险操作 |
| product-group-delete | 商品组详情删除菜单项 | 危险操作，仅 workspace 可编辑角色显示 |
| product-group-delete-confirm-dialog | 商品组删除确认弹窗 | 确认后商品组和全部款式软删除 |
| product-group-variant-remove-{index} | 商品组款式移除按钮 | 保存商品组时将对应款式软删除 |
| product-group-variant-remove-confirm | 商品组款式移除确认弹窗 | 取消保留款式，确认后从当前编辑表单移除 |
