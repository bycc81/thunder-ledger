# 批次与工作区软删除定位 ID 注册表

本轮保留既有删除定位 ID，并为批次详情页的危险操作增加稳定 ID。

| ID | 页面 | 用途 |
|---|---|---|
| `batch-more-{batchId}` | 批次列表 | 打开指定批次的更多操作 |
| `batch-delete-confirm` | 批次列表 | 删除批次二次确认弹窗 |
| `batch-danger-zone` | 批次详情 | 危险操作区域 |
| `batch-detail-delete` | 批次详情 | 打开删除批次确认 |
| `batch-detail-delete-confirm` | 批次详情 | 删除批次二次确认弹窗 |
| `workspace-delete` | 工作区管理 | 打开删除工作区确认 |
| `workspace-delete-confirm` | 工作区管理 | 删除工作区二次确认弹窗 |
| `workspace-system-admin-notice` | 工作区管理 | 说明系统管理员无需加入或退出工作区 |
