# B5 data-ai-id 注册表

| `data-ai-id` | 类型 | 用途 |
|---|---|---|
| `b5-report-page` | 页面根节点 | 报表工作台页面 |
| `report-filter` | 区域 | 报表筛选区域 |
| `report-type-selector` | 控件 | 切换报表类型 |
| `report-batch-selector` | 控件 | 选择批次范围 |
| `report-date-range` | 控件 | 选择日期范围 |
| `report-query` | 控件 | 查询报表 |
| `report-export` | 控件 | 发起 CSV 导出 |
| `report-summary` | 区域 | 报表汇总指标 |
| `report-summary-{summaryKey-kebab-case}` | 指标 | 当前报表返回的汇总指标 |
| `report-result-list` | 列表 | 报表明细 |
| `report-result-item-{recordId}` | 列表项 | 单条报表明细 |
| `report-loading` | 状态 | 报表加载中 |
| `report-empty` | 状态 | 报表无数据 |
| `report-error` | 状态 | 报表加载错误 |
| `report-permission` | 状态 | 报表无权限 |
| `report-export-dialog` | 弹窗 | 导出范围确认 |
| `report-export-confirm` | 控件 | 确认导出 |
| `report-export-cancel` | 控件 | 取消导出 |
| `operation-record-page` | 页面根节点 | 操作记录页面，保留既有 ID |
| `operation-record-filter` | 区域 | 审计筛选区域 |
| `operation-record-action` | 控件 | 按动作筛选 |
| `operation-record-actor` | 控件 | 按操作者筛选 |
| `operation-record-date-range` | 控件 | 按时间范围筛选 |
| `operation-record-query` | 控件 | 查询审计记录 |
| `operation-record-refresh` | 控件 | 刷新审计记录，保留既有 ID |
| `operation-record-list` | 列表 | 审计记录列表，保留既有 ID |
| `operation-record-{recordId}` | 列表项 | 单条审计记录，保留既有模式 |
| `operation-record-empty` | 状态 | 审计记录为空，保留既有 ID |
| `operation-record-loading` | 状态 | 审计记录加载中 |
| `operation-record-error` | 状态 | 审计查询错误 |
| `operation-record-permission` | 状态 | 审计无权限，保留既有 ID |
