# B5 产品与 UX 定义

## 结论与确认

B5 首期交付报表工作台、权限范围内 CSV 导出和管理员操作记录查询；这些能力只读业务数据，不改变库存、销售、费用或结算主流程。备份恢复不做普通用户在线功能，仅建立运维演练、备份检查和发布门禁记录，真实生产恢复仍需单独确认。原型位于 `prototype/index.html`，原型和权限边界已于 2026-09-15 确认。

## 用户、问题与范围

- 目标用户/角色：工作区所有者、管理员；编辑者和查看者可查看其有权批次的报表，但不能查看工作区审计或执行导出超出自身数据范围。
- 使用场景与触发入口：从工作区进入“报表”；在报表中切换批次、选择日期范围和报表类型；管理员从“操作记录”进入审计查询。
- 当前问题：B1-B4 已产生库存、销售、费用、成本和结算数据，但缺少统一的只读汇总、权限内导出和可检索的操作追踪。
- 产品目标：让用户快速核对经营结果，让管理员能追踪关键操作，同时不改变既有账务事实。
- 用户完成任务后的可观察结果：看到与业务明细和已确认账单一致的汇总；下载当前权限范围内的 CSV；按条件找到操作记录。
- 本次做什么：库存、销售、利润、成员贡献、待结算报表；CSV 导出；审计查询筛选和分页/限量展示；备份恢复运维演练记录和发布前检查清单。
- 本次不做什么：不改写业务数据；不新增自动结算规则；不接入外部平台；不提供普通用户在线恢复、删除数据库或覆盖生产数据；不实现新的多租户和 SaaS 计费。

## 用户流程、规则与场景

### 用户主流程

```text
工作区 → 报表 → 选择批次/报表类型/时间范围 → 查看汇总与明细 → 导出当前权限范围 CSV
工作区 → 操作记录 → 选择动作/操作者/时间范围 → 查看审计记录
运维发布前 → 备份检查 → 隔离环境恢复演练 → 记录结果 → 才允许生产发布
```

正常路径是只读查询和导出。主要分支包括无批次、无数据、无权限、查询失败和导出失败。危险操作只有运维恢复演练，生产恢复不在业务页面内执行。

### 业务规则与权限

- 角色和可见范围：
  - 所有者、管理员：查看其工作区范围内的报表、导出和操作记录。
  - 编辑者、查看者：查看其参与批次和私有记录规则允许的报表；导出不得超过 API 返回的数据范围。
  - 编辑者、查看者：不能查看工作区级审计记录。
  - 系统管理员：只负责账号管理，不因系统管理员身份自动获得其他工作区业务数据。
- 可执行操作：选择报表条件、刷新、查看明细、导出 CSV；管理员可筛选审计记录。
- 状态和状态转换：查询条件变化后处于待查询状态；提交查询后为加载中；成功显示结果；无结果显示空状态；请求失败显示可重试错误。
- 不可破坏的业务规则：
  - 报表必须使用现有 API 权限和批次范围。
  - 利润报表必须与已确认结算账单及当前未结算流水使用同一金额精度和成本口径。
  - 导出字段不得包含未授权记录或不必要的敏感字段。
  - 审计记录只追加，不允许在报表页面编辑或删除。
  - 恢复演练不得连接生产数据库写入，不得覆盖生产数据。

### 需求场景

#### Requirement:

系统 SHALL 根据当前用户权限返回库存、销售、利润、成员贡献和待结算报表。

#### Scenario:

- **WHEN** 用户选择自己有权访问的批次和日期范围并查询
- **THEN** 系统显示汇总指标、明细列表和数据更新时间，金额按现有角精度展示。

#### Requirement:

系统 SHALL 让用户导出与当前 API 权限范围一致的 CSV。

#### Scenario:

- **WHEN** 用户点击导出
- **THEN** 系统确认报表类型和筛选范围，成功后下载 CSV；越权范围被服务端拒绝并记录失败结果。

#### Requirement:

系统 SHALL 只允许工作区所有者和管理员查询该工作区审计记录。

#### Scenario:

- **WHEN** 管理员按动作、操作者或时间范围查询
- **THEN** 系统显示操作者、动作、对象、时间和必要的结果摘要，不显示密码、Token、连接串或完整敏感数据。

#### Requirement:

系统 SHALL 在生产发布前要求完成备份可用性检查和隔离环境恢复演练。

#### Scenario:

- **WHEN** 恢复演练未通过或没有可验证备份
- **THEN** 发布门禁保持阻断，不能把该状态标记为已具备生产恢复能力。

## 页面与交互规格

### 页面地图

```text
工作区
  ├─ 报表工作台
  │   ├─ 报表筛选
  │   ├─ 汇总与明细
  │   └─ CSV 导出确认
  └─ 操作记录
      └─ 审计筛选与结果

运维文档
  └─ 备份恢复演练记录，不作为普通用户页面
```

### 页面：报表工作台

- 核心任务：核对某批次或工作区范围内的经营数据并导出。
- 进入条件：已登录；至少有一个可读取的工作区或批次。
- 离开/下一步：返回工作区；导出后留在当前报表。
- 信息层级：报表类型与范围 → 关键汇总 → 明细 → 数据说明。
- 主操作：查询/刷新。
- 次要操作：切换报表类型、选择批次、选择时间范围、导出。
- 危险操作与确认：无业务写操作；导出确认弹窗提示范围和字段。

#### 线框

```text
[报表]                         [切换工作区]
[报表类型] [批次] [日期范围]
[查询]                         [导出 CSV]
[总库存] [销售额] [利润] [待结算]
[汇总说明]
[明细列表]
[加载/空/错误状态]
```

#### 关键字段与控件

| 区域 | 字段/控件 | 控件类型 | 必填/可选 | 校验或说明 |
|---|---|---|---|---|
| 筛选 | `reportType` | 分段控件 | 必填 | inventory、sales、profit、members、unsettled |
| 筛选 | `batchId` | 选择器 | 可选 | 仅显示当前用户可读取批次 |
| 筛选 | `from`、`to` | 日期选择器 | 可选 | 开始日期不得晚于结束日期 |
| 汇总 | 指标卡 | 只读 | - | 销售报表固定展示销售额、销售成本、销售利润（未扣费用）、销售数量；金额使用现有精度和格式 |
| 结果 | 明细列表 | 只读列表 | - | 不展示越权数据 |
| 操作 | 导出 | 按钮 | - | 服务端重新校验权限并写入审计 |

#### 交互与反馈

- 成功：显示汇总、明细、查询条件和更新时间。
- 失败：显示错误原因和重试操作。
- 保存/提交中：查询和导出按钮显示 loading，避免重复请求。
- 返回、取消和未保存变更：页面无未保存业务变更，返回直接离开。
- 弹窗、抽屉、跳转：导出前打开确认弹窗；不使用恢复弹窗。

### 页面：操作记录

- 核心任务：管理员追踪工作区关键操作。
- 进入条件：已登录且拥有工作区 owner/admin 权限。
- 离开/下一步：返回工作区或切换工作区。
- 信息层级：筛选条件 → 结果数量 → 操作记录。
- 主操作：查询/刷新。
- 次要操作：动作、操作者、时间范围筛选。
- 危险操作与确认：无删除和编辑操作。

#### 线框

```text
[操作记录]                     [切换工作区]
[动作] [操作者] [时间范围]
[查询]                         [刷新]
[记录列表：动作 / 对象 / 操作者 / 时间]
[无权限/空/错误状态]
```

#### 关键字段与控件

| 区域 | 字段/控件 | 控件类型 | 必填/可选 | 校验或说明 |
|---|---|---|---|---|
| 筛选 | `action` | 选择器 | 可选 | 使用服务端支持的动作集合 |
| 筛选 | `actorUserId` | 选择器 | 可选 | 仅显示当前工作区成员 |
| 筛选 | `from`、`to` | 日期选择器 | 可选 | 时间范围限制在合理查询窗口 |
| 结果 | 审计记录 | 只读列表 | - | 最多按接口约定展示一页 |

#### 交互与反馈

- 成功：显示最新记录，时间按 Asia/Shanghai 展示。
- 失败：显示可重试错误，不伪造空数据。
- 保存/提交中：查询按钮 loading。
- 返回、取消和未保存变更：无未保存变更。
- 弹窗、抽屉、跳转：无必要弹窗。

## 状态、响应式与验收

### 状态覆盖

| 状态 | 页面表现 | 可执行操作 |
|---|---|---|
| Loading | 结果区域显示加载状态，筛选条件保持可见 | 取消或等待 |
| Empty | 显示当前范围暂无数据，并保留修改条件入口 | 修改条件、刷新 |
| Error | 显示错误提示和重试按钮 | 重试、返回 |
| 无权限 | 显示无权访问说明，不加载数据 | 返回工作区 |
| Disabled | 没有可读批次或正在请求时禁用查询/导出 | 等待或选择有效范围 |
| Success | 显示指标、明细、更新时间和可用操作 | 切换条件、导出 |

### 响应式与视觉边界

- 桌面端：不单独维护桌面布局；宽屏使用移动端内容约束，避免表格横向挤压。
- 移动端：目标视口 390×844 和 430×932；筛选单列或可横向滚动的 Vant 分段控件，明细使用列表而非宽表格。
- 键盘焦点和触控目标：控件触控区域不小于 44px；弹窗焦点顺序清晰；按钮使用文字和现有 Vant 图标。
- 复用的现有页面/组件：`MobileShell`、工作区切换 Popup、现有状态组件和 `OperationRecordsPage` 的权限呈现方式。
- 视觉方向与禁止模式：遵循当前移动端规范；不使用营销式 Hero、渐变背景或多层卡片。
- 原型：`prototype/index.html`

### 页面验收

- [ ] 用户能从工作区找到报表入口并完成查询
- [ ] 用户能在当前权限范围内完成 CSV 导出
- [ ] owner/admin 能筛选操作记录，其他角色看到无权限状态
- [ ] Loading、Empty、Error、无权限和 Disabled 状态可见
- [ ] 报表汇总与明细口径可追溯到 B1-B4 数据
- [ ] 原型关键业务节点已登记稳定 `data-ai-id`
- [ ] 备份恢复演练记录包含备份、恢复、校验和回滚结果
- [x] 用户已直接打开原型确认页面结构、主流程和关键交互
