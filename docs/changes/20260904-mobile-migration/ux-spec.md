# UX/UI 规格：B1 移动端工作台

## 结论

采用移动端 H5 页面和底部主导航，顶部固定显示当前工作区。页面以列表、Cell、Tag、Dialog 和 Popup 为主，不压缩 PC 表格，也不把所有操作塞进一个页面。统计信息横向滑动，业务列表单列呈现，详情使用全屏弹窗，确保单手操作和窄屏可读性。原型位于 `prototype/index.html`，确认后才进入 Vue/Vant 实现。

## 页面地图

```text
登录
  └─ 工作区外壳
      ├─ 工作区（概览、成员）
      ├─ 批次
      ├─ 操作记录
      └─ 我的
```

## 核心交互

- 顶部工作区按钮打开 Popup/Picker，切换后刷新所有工作区范围数据。
- 底部 TabBar 进入工作区、批次、操作记录和我的。
- 批次列表使用移动端列表项，显示名称、状态、我的角色和创建时间；删除位于更多操作。
- 批次详情使用全屏 Dialog，显示基本信息和参与人；“添加参与人”打开独立 Dialog。
- 成员角色用 Tag 区分；邀请时间为空时显示“--”。
- 删除、移除使用红色按钮和确认 Dialog；确认按钮明确写“删除”或“移除”。

## 视觉边界

- 亮色画布、白色表面、细分隔线和深青绿色主色（参考成熟 Vant 移动端后台的克制用色）；不使用橘色大面积铺陈、渐变、Hero 或卡片墙，也不使用桌面端外框或居中的后台容器。
- 统计指标使用横向可滚动的小块；批次和成员使用单列列表，操作按钮按窄屏宽度自动换行或纵向排列。
- 页面区块不额外套表格外框；列表项保持 16px 左右内边距和舒适行高。
- 标签和值在详情中同一行，字段标签右对齐；说明文字使用较小字号。
- 所有触控目标最小 44px，页面不得出现横向溢出。

## 语义化定位

原型中的页面根节点、导航、工作区选择、批次项、成员项、弹窗和危险操作均添加稳定的 `data-ai-id`。重复项包含业务 ID；ID 不依赖展示文案，不用于 CSS。

## 状态覆盖

- Loading：保留页面结构并禁用提交按钮。
- Empty：给出创建批次、邀请成员或切换工作区的下一步操作。
- Error：页面级重试和操作级错误，保留用户输入。
- 无权限：显示只读说明，不仅隐藏按钮。
- 成功：Toast 说明具体动作并刷新事实列表。

## 原型验收

- [ ] 可从底部导航找到四个主模块。
- [ ] 可切换当前工作区并理解数据范围。
- [ ] 批次详情和添加参与人是独立弹窗。
- [ ] 批次列表有创建时间，成员列表有邀请时间和角色标签。
- [ ] 删除和移除均有二次确认。
- [ ] 关键元素具备 `data-ai-id`，移动端视口无溢出。
- [ ] 用户已打开原型确认页面结构和主流程。
