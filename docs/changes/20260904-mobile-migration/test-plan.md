# 测试与验收计划：B1 移动端工作台

## 结论

证明移动端入口能在当前工作区上下文中安全完成批次、成员和操作记录任务，并且关键控件可通过稳定的 `data-ai-id` 定位。

## 验收场景

- 登录成功、验证码错误、会话失效后重新登录。
- 切换工作区后批次、成员和操作记录均刷新且不串数据。
- 创建批次、打开详情、编辑名称、添加参与人和删除批次。
- 邀请成员、调整角色、移除成员；所有者不可移除或降级。
- 查看者进入页面时为只读，无权限操作有明确反馈。
- 空列表、加载、请求失败、长名称和小屏视口。
- `data-ai-id` 在页面区域、列表项、弹窗和危险操作上稳定存在。

## 自动化验证

实现阶段执行 `apps/web` 的 `npm run typecheck` 和 `npm run build`，关键流程测试优先使用 `data-ai-id`。

## 人工验收

直接打开 `prototype/index.html`，在手机宽度下完成登录、切换工作区、打开批次详情、添加参与人、删除确认和退出登录流程。

## 结果

已完成 Web typecheck 和 build。待连接开发 API 后进行真实登录、权限和移动端浏览器冒烟验收。
