# 产品定义：B1 移动端工作台

## 结论

将当前单页 PC 工作台迁移为移动端优先的 H5/PWA，复用现有 API 和权限规则。工作区、批次、成员和操作记录按独立任务分区，降低查找和误操作成本。本阶段先完成 Product/UX 原型确认，确认后再进入 Vue/Vant 技术设计。

## 用户与场景

- 目标用户/角色：工作区所有者、管理员、编辑者、查看者。
- 使用场景与触发入口：登录后进入当前工作区，随时切换工作区并管理批次协作。
- 当前问题：所有功能集中在单页，PC 表格和菜单层级不适合移动端，批次和成员操作不够明确。

## 目标与范围

- 产品目标：用户能在明确的工作区上下文中完成概览、批次、成员和操作记录任务。
- 可观察结果：创建批次后可在列表看到创建时间和状态；批次详情可管理参与人；成员页可邀请和调整角色；操作记录只显示当前工作区。
- 本次做什么：移动端导航、工作区切换、批次 CRUD、成员与参与人管理、操作记录、登录态和权限反馈、语义化 `data-ai-id`。
- 本次不做什么：不修改后端 API/数据库，不新增商品、订单、库存、结算或原生 App。

## 用户主流程

```text
登录 → 当前工作区 → 概览
  ├─ 批次 → 新建/打开详情 → 添加参与人/删除
  ├─ 工作区成员 → 邀请/调整角色/移除
  └─ 操作记录 → 查看当前工作区记录
```

危险操作包括删除批次、移除工作区成员和移除批次参与人，均需二次确认。

## 页面清单

| 页面 | 主任务 | 关键状态 |
|---|---|---|
| 登录 | 建立会话 | 验证码、失败、加载 |
| 工作区概览 | 查看状态和最近批次 | 空工作区、空批次、错误 |
| 批次列表 | 搜索、筛选、创建、删除 | 空列表、加载、无权限 |
| 批次详情 | 查看信息和管理参与人 | 只读、保存、删除确认 |
| 成员管理 | 邀请、角色调整、移除 | 无权限、邀请结果 |
| 操作记录 | 查看当前工作区操作 | 空记录、无权限 |
| 我的 | 查看账号、退出登录 | 会话失效 |

## 业务规则

- 当前工作区是所有批次、成员和操作记录请求的上下文。
- 前端显隐不等于授权，API 必须再次校验权限。
- 所有者不可被降级或移除；查看者只能查看。
- 角色使用 owner/admin/editor/viewer，并在界面以标签呈现。
