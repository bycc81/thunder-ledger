# 页面契约

> 适用范围：新页面、新模块、多页面流程或明显改变用户操作路径的前端任务。本文是产品/UX 原型与 API、技术设计、实现之间的共同契约。

## 使用规则

- 产品需求和 UX 规格确认后，API 设计和 Vue 实现前必须完成页面契约。
- 页面契约描述业务需要，不按组件名称或前端文件组织接口。
- 每个具体需求在 `docs/changes/YYYYMMDD-feature/page-contract.md` 保存一份实例；模板只定义结构，不替代实例。
- 原型调整涉及字段、操作、权限、状态或定位 ID 时，必须同步更新本契约。
