# UX/UI 规格

> 适用范围：已完成 `product-brief.md` 的新模块或新页面。本文只决定页面如何帮助用户完成已确认的产品目标，不替代技术设计或前端设计系统。

## 页面验收

- [ ] 用户能从入口找到主操作并完成主流程
- [ ] 主操作、次要操作和危险操作层级清晰
- [ ] Loading、Empty、Error、无权限和 Disabled 状态可见
- [ ] 桌面端和移动端布局可用
- [ ] 成功、失败和取消反馈符合现有设计系统
- [ ] 用户已直接打开原型确认页面结构、主流程和关键交互
