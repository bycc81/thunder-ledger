# ThunderLedger 自审清单

适用于单人开发。清单用于发现遗漏，不代表额外审批；L2 的生产或不可逆操作仍需用户明确确认。

## L0

- 目标和改动范围清楚。
- 文档链接、命令和路径有效。
- 未引入密钥、隐私或无关技术栈。

## L1

- 页面/API/数据行为与目标一致。
- 相关 typecheck、test 或 build 已执行。
- 表单校验、错误提示、空态和加载态已考虑。
- UI 遵守 `docs/standards/frontend/` 的布局、颜色和组件规范。

## L2

- 设计记录写明影响范围、数据变化、权限边界和非目标。
- 数据库迁移可重复执行，必要时有备份和回滚方案。
- 认证、授权、敏感数据和日志脱敏已验证。
- 已完成专项测试、健康检查或人工验收。
- 生产/不可逆动作已向用户说明并获得确认。

## 交付前

- 改动摘要、验证命令和结果已记录。
- 未验证项、残留风险和后续动作已列出。
- 文档引用与实际目录一致，未残留旧平台专属术语。
