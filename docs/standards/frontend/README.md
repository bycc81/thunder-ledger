# ThunderLedger 设计系统

ThunderLedger 当前采用移动端优先的经营工作台，强调任务、批次和协作信息的清晰组织。移动端使用轻量画布、白色表面、深青绿色主操作和低饱和状态色；旧版桌面端的珊瑚色规范仅用于历史追溯。

当前规范见 [frontend-guidelines.md](frontend-guidelines.md)。

语义化定位规范见 [data-ai-id-guidelines.md](data-ai-id-guidelines.md)。

历史桌面端规范见 [frontend-guidelines-pc-legacy.md](frontend-guidelines-pc-legacy.md)，不作为移动端实现依据。
