# ThunderLedger 使用手册

> 适用范围：ThunderLedger Web 移动端（2026-09）。
> 适用对象：店主、合买发起人和协作成员。
> 站内访问：登录后打开 `/help/user-manual`。

ThunderLedger 按“工作区 → 批次 → 库存与交易 → 结算”管理一次经营活动。商品资料归工作区共享；采购、库存、销售、费用和账单都归属于具体批次。

## 1. 先选对操作

| 你要做什么 | 应该进入哪里 | 何时使用 |
| --- | --- | --- |
| 建立协作空间、管理商品 | 工作区 | 准备商品资料、邀请成员时 |
| 开始一轮采购或合买 | 新建批次 | 每次共同采购建议单独建一个批次 |
| 录入到货与成本 | 批次 → 库存 | 已采购商品，需要形成可卖库存时 |
| 卖出一个已有库存商品 | 批次 → 交易 → 普通销售 | 商品、数量和库存来源都明确时 |
| 一次卖多件、组合售出或不建商品直接卖 | 批次 → 交易 → 快速售出 | 需要自由填写商品项，或只关联部分既有库存时 |
| 记录邮费、包装费等 | 批次 → 交易 → 其他费用 | 发生了实际垫付费用时 |
| 计算成员间应收应付 | 批次 → 结算 | 一批交易完成，需要生成阶段账单时 |

一次常见流程：

```text
创建/切换工作区 → 新建批次 → 添加商品 → 新增采购形成库存
→ 普通销售或快速售出 → 记录其他费用 → 创建账单并完成转账
```

## 2. 核心概念

| 概念 | 说明 |
| --- | --- |
| 工作区 | 长期存在的个人或团队经营空间，例如“小卡合买”。同一工作区内成员共享商品库和批次。 |
| 批次 | 一次共同采购、共同售卖的独立账务主体；库存、交易、费用和结算都在批次内隔离。 |
| 商品 / 商品组 | 商品是可复用资料；商品组适合一组多个款式的场景，每个款式可独立采购和售卖。 |
| 库存 | 批次内可卖的既有商品数量，来源于采购。 |
| 普通销售 | 销售一件已有库存商品；保存后按该商品和数量扣减库存。 |
| 快速售出 | 一张可包含多个自由商品项的售出单；每项可选择是否关联零到多个既有库存。 |
| 本单成本 | 快速售出时手工填写的成本，允许为 `0`；它是快速售出结算和利润的成本口径。 |
| 结算 | 将未结账的普通销售、快速售出及费用锁定为阶段账单，计算利润和成员间应收/应付。 |

## 3. 角色与权限

工作区和批次分别维护成员与角色。前端隐藏按钮不代表服务端会放行越权操作。

| 角色 | 可以做什么 |
| --- | --- |
| 工作区所有者 | 管理成员、改名、删除工作区，拥有全部经营权限。 |
| 工作区管理员 | 管理成员和角色，拥有与所有者接近的经营权限；不是创建人时不能改名或删除工作区。 |
| 工作区编辑者 | 新建批次、维护商品、参与采购、普通销售、快速售出和费用录入。 |
| 工作区查看者 | 只能查看有权访问的数据。 |
| 批次所有者 | 管理批次成员、删除批次、创建和确认结算账单。 |
| 批次编辑者 | 新增采购、记录交易、撤销未结账交易。 |
| 批次查看者 | 只能查看批次内数据。 |

工作区所有者或管理员在批次内通常也拥有相应的管理与编辑能力；只有批次参与人能查看该批次的数据。

## 4. 工作区与批次

### 4.1 创建和切换工作区

- 登录后系统会创建个人工作区。
- 需要协作时，点击顶部当前工作区 → **创建工作区** → 填写名称。
- 点击顶部工作区名称可切换工作区。商品、批次和成员按工作区隔离。

### 4.2 管理工作区成员

- 工作区首页 → 快捷操作 → **管理成员**。
- 点击 **添加成员**，可生成一次性注册链接，或直接加入已有平台账号。
- 添加时选择管理员、编辑者或查看者；之后可修改角色或移除成员。

### 4.3 新建和管理批次

- 在工作区首页或“批次”页点击 **新建批次**，填写名称即可。
- 建议按“一次共同采购 / 一轮合买”建立一个批次，便于库存和结算独立核算。
- 批次详情提供三个直接入口：
  - **库存**：查看库存、登记采购；
  - **交易**：记录普通销售、快速售出和费用；
  - **结算**：创建账单、查看应收应付。
- 批次所有者可在详情页添加参与人、调整编辑者/查看者角色或移除成员。

### 4.4 删除工作区或批次

- 工作区：顶部工作区名称 → **管理当前工作区**；仅创建人可改名或删除，非创建人可退出。
- 批次：批次列表“⋯”菜单，或批次详情底部 **危险操作** → **删除批次**。
- 删除为软删除：记录保留，但对象从界面隐藏且不可继续操作；均需二次确认。

## 5. 商品

商品库属于当前工作区。所有成员可查看；工作区所有者、管理员和编辑者可新建、编辑。

### 5.1 商品与商品组

- 底部导航进入 **商品**。可搜索名称，查看图片、描述、参考价和类型。
- **新建商品**：商品名称必填；图片最多 5 张，首张作为列表首图；描述和参考价可选。
- **新建商品组**：适合“同一弹、多款式”。逐款添加款式后，每个款式都可独立采购和普通销售。
- 商品组可使用组合模板预填款式；已有采购、上架或销售记录的款式不能删除。
- 修改商品资料不会改写已发生采购、交易或账单中的名称快照。

## 6. 库存与采购

库存是批次内的可卖数量。可卖数量会扣除损坏/丢失、未撤销普通销售，以及**已关联库存的未撤销快速售出**；未关联库存的快速售出不改变库存。

### 6.1 新增采购

批次详情 → **库存** → **新增采购**。填写：

| 字段 | 说明 |
| --- | --- |
| 商品 / 商品组 | 必填；选择当前工作区商品。商品组需要逐款填写。 |
| 采购渠道 | 必填；可选择已有渠道或当场新增。 |
| 付款人 | 必填；实际付款的批次参与人。 |
| 数量 | 必填正整数。 |
| 总成本 | 必填，非负，最多两位小数；允许填写 `0`。 |
| 成本由谁承担 | 必填；可添加多位参与人，承担金额合计必须等于总成本。总成本为 `0` 时，各承担金额可均为 `0`。 |
| 采购日期 / 来源链接 / 备注 | 采购日期必填，其余可选。 |

保存后，同一商品的采购数量和成本会在库存汇总中合并，采购明细仍会保留渠道、付款人和成本承担。

> 成本承担不等于付款金额。例如 A 支付 60 元、B 支付 70 元，总成本 130 元，仍可由 A、B 各承担 65 元。

### 6.2 更正采购和减少库存

- 商品库存详情 → 采购明细 → 编辑采购。
- 商品未卖出前，可直接修改数量和成本；卖出后数量只读，更正成本必须填写原因，并在结算页生成待处理调整。
- 商品库存详情右上角 **更多操作** → **登记商品损坏或丢失**，填写减少数量和原因。数量不得超过当前可卖数量。

## 7. 交易：普通销售、快速售出与费用

批次详情 → **交易**。销售页会同时展示两种来源标签：**普通销售**、**快速售出**；费用在“费用”页签中查看和新增。

### 7.1 何时使用普通销售，何时使用快速售出

| 场景 | 选择 |
| --- | --- |
| 卖一个已有库存商品，数量明确 | 普通销售 |
| 同时卖多个商品或组合 | 快速售出 |
| 商品未建档、不需要建立库存 | 快速售出，不关联库存 |
| 需要从多种既有库存扣减 | 快速售出，关联多个库存 |

### 7.2 普通销售

销售页右上角点击 **普通销售**。适用于单个已有库存商品。

| 字段 | 说明 |
| --- | --- |
| 商品 | 必填；只显示可卖数量大于 0 的商品。商品组先选组，再选款式。 |
| 数量 | 必填；可加减或直接输入，范围为 1 到当前可卖数量。 |
| 成交总价 | 必填，最多两位小数。 |
| 销售渠道 | 可选，例如“闲鱼”。 |
| 平台手续费 | 可选；支持按比例或按金额，页面会预览手续费和预计实收。 |
| 卖出人 | 必填；卖出人就是这笔实际收款人。 |
| 成交时间 / 备注 | 成交时间必填，备注可选。 |

点击 **保存并减少库存** 后，系统扣减对应商品库存；实际收款 = 成交总价 − 手续费。

### 7.3 快速售出

销售页右上角点击 **快速售出**。一张单可添加多个商品项，不要求先建商品，也不要求每项关联库存。

先填写整单信息：

| 字段 | 说明 |
| --- | --- |
| 成交总价 | 必填，整张快速售出单的成交金额。 |
| 卖出人 | 必填；实际收款人。 |
| 成交时间 | 必填。 |
| 销售渠道 / 备注 | 可选。 |
| 平台手续费 | 可选；可选无、按比例或按金额，页面会预览手续费和预计实收。 |

每个商品项都要填写：

| 字段 | 说明 |
| --- | --- |
| 商品名 | 必填，可自由填写，不会自动创建商品。 |
| 售出数量 | 必填正整数，可通过步进器加减或直接输入。 |
| 本单成本 | 必填，允许 `0`；这是详情、利润和结算使用的成本。关联库存后可点击 **按库存成本** 带入，再手工修改。 |
| 关联库存 | 可选开关。开启后点击 **添加关联库存**，可多选当前批次仍有可用量的库存商品，并分别填写关联数量。 |

关联库存的规则：

- 只有被关联的库存才会在保存后扣减；未关联商品项不会扣库存，也不会新建商品或采购。
- 每个关联数量最少 1，最多为该商品当时可用数量；同一库存跨商品项的关联总数也不能超过可用量。
- 售出数量和关联库存数量可以不同。保存时系统会提示确认，但**不会擅自修改任何数量**；请按实际业务判断后再确认。
- 详情会同时显示“本单成本（结算口径）”和“库存账消耗成本（系统）”。两者可能不同：前者用于结算，后者只用于准确维护库存成本。

保存后，进入快速售出详情，可查看收款、成本、商品明细、关联库存、关联费用和结算状态。

### 7.4 记录其他费用

切换到 **其他费用** 页签 → **记录其他费用**：

| 字段 | 说明 |
| --- | --- |
| 费用类型 / 名称 | 邮费或自定义；自定义时填写名称。 |
| 金额 | 必填，最多两位小数。 |
| 付款人 | 必填；实际垫付人。 |
| 关联销售 / 关联快速售出 | 可选；最多关联其中一种交易。关联后会随该交易自动纳入结算。 |
| 发生时间 / 备注 | 发生时间必填，备注可选。 |

### 7.5 撤销、状态和详情

- 未结账且未撤销的普通销售、快速售出和费用都可撤销；必须填写撤销原因并二次确认。
- 撤销普通销售会恢复该销售扣减的库存；撤销快速售出会恢复其**关联库存**，未关联库存的商品项无需恢复。
- 已纳入账单的交易不能撤销；已撤销记录保留原因和状态，不能重复撤销。
- 点击交易列表项可进入详情。快速售出详情会明确标注“快速售出”，并显示待结账、已结账或已撤销状态；已结账可跳转对应账单。

## 8. 结算

结算将未结账的普通销售、快速售出和相关费用锁定为阶段账单，生成利润分配和成员间转账建议。确认后，本次选中的交易、费用和利润比例都会锁定，不能再次纳入账单。

### 8.1 结算首页

批次详情 → **结算**。页面显示待结算交易数量、采购更正产生的待处理调整，以及已确认账单。

只有批次所有者或工作区所有者/管理员可开始结算；查看者只能查看已确认账单。

### 8.2 创建账单（三步）

**第 1 步：选择交易和费用**

- 勾选本次要结算的普通销售和快速售出；快速售出会带来源标签。
- 关联到已选交易的费用会强制纳入；未关联费用可自行选择。
- 至少选择一笔普通销售或快速售出才能继续。

**第 2 步：确认利润比例**

- 页面展示本次商品成本和各成员成本承担；结算时不能手动修改成本承担。
- 普通销售按库存成本计算；快速售出按商品项填写的**本单成本**计算。
- 填写各成员利润比例，合计必须为 100%。

**第 3 步：预览并确认**

- 核对销售额、手续费、净收款、商品成本、其他费用和利润。
- 核对每位成员的利润分成、成本返还、垫付费用、已收销售款和应收/应付。
- 点击 **确认账单** 并完成二次确认，账单随即锁定。

### 8.3 账单和调整单

- 账单详情为只读，可查看汇总、成员结果、转账建议及纳入的普通销售、快速售出和费用。
- 已结账商品的采购成本被更正时，结算页会出现 **待处理调整**。进入后核对旧成本、新成本和成员差额，再确认调整。

## 9. 常见问题

- **快速售出不关联库存可以吗？** 可以。仍需填写商品名、售出数量、本单成本、成交总价和卖出人；不会扣库存，也不会创建商品。
- **快速售出的本单成本能填 0 吗？** 可以，但不能为空；`0` 或 `0.00` 都有效。
- **快速售出的售出数量必须等于关联库存数量吗？** 不强制相等。系统会在保存前提示确认，但不会自动替你改数值。
- **为什么普通销售里可卖数量变少了？** 除普通销售和库存减少外，已关联库存的未撤销快速售出也会占用并扣减可卖库存。
- **为什么不能保存普通销售？** 请确认已选商品、数量未超过当前可卖数量、成交总价和卖出人已填写。
- **为什么不能撤销交易？** 交易可能已结账或已撤销。已结账记录需按结算调整流程处理，不能直接撤销。
- **为什么没有“开始结算”？** 可能没有待结账交易，或当前角色不是批次所有者 / 工作区所有者 / 管理员。
- **金额可以填几位小数？** 最多两位；系统按分计算，超出两位小数会被拒绝。
- **为什么库存数量不对？** 核对采购、损坏/丢失、未撤销普通销售，以及关联库存的未撤销快速售出。
- **报表和操作记录在哪里？** 工作区首页 → 快捷操作 → **报表** 或 **查看操作记录**；可按权限范围筛选和导出。

## 10. 操作前检查

- 采购前：确认付款人、成本承担人和总成本；成本承担合计必须等于总成本。
- 普通销售前：确认商品和当前可卖数量。
- 快速售出前：确认每个商品项的本单成本；若关联库存，确认选中的库存和关联数量。
- 结算前：确认交易、关联费用和利润比例；账单确认后不能直接修改或重复结算。
